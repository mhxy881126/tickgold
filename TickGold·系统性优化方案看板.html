合规与安全红线

同花顺 UI 自动化存在真实政策风险。
  • 不破解/不注入/不修改同花顺客户端，仅模拟用户本人操作
  • 实盘默认关闭，开启需武装+限额+价格偏离+二次确认+全量审计
  • 不做投顾、代客理财、收益承诺、确定性预测
  • 风控/执行是确定性代码，AI 永远不可绕过
  • 行业警示：easytrader 已被监管整体清空，长期保留「模拟可用、实盘仅授权辅助」定位
  • HTTP API 仅 127.0.0.1、默认只读、下单显式开启+token+审计
