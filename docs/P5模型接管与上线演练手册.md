# P5 模型接管与上线演练手册

> 适用版本：TickGold 3.1.1（P5）
> 目标：让 AI 模型从"只出主意"安全过渡到"可被授权下单"，全程做到**故障可降级、一键可急停、随时可回退**。
> 阅读对象：已熟悉模拟盘与券商通道设置的使用者。第一次使用请先完整阅读《真实通道上线手册》（P4）。

---

## 1. 一条主线：四阶段灰度，绝不一步到位

模型接管在「作战驾驶舱 → 模型接管控制台」中操作，状态机分四阶段，**只能逐级申请、人工审批后切换**，规则脑始终保留、可随时一键回退：

| 阶段 | 谁来下单 | 说明 |
| --- | --- | --- |
| ① 规则脑 rule | 成熟规则引擎 | 默认阶段。你在自动交易里选的脑（rule/laya/云端 LLM）照常工作。 |
| ② 影子对比 shadow | 仍是规则脑 | AI 与规则脑对每只盯盘标的**并行出主意，只记录、不执行**，用于积累对比样本。 |
| ③ 灰度接管 canary | 规则脑 + 少量 AI | 按标的代码做确定性分流：同一只票始终走同一个脑。被分到 AI 的票由 AI 决策，且**强制小仓位**。 |
| ④ 模型接管 live | AI 全量 | AI 接管全部信号，规则脑兜底。任何异常自动降级、累计失败自动回退。 |

设计要点：

- **只进一级**：规则脑不能直接申请 live，必须先影子、再灰度，杜绝"一步到全自动"。
- **人工审批**：每次阶段切换都要第二下"同意并切换"，申请与审批是两次独立确认。
- **随时回退**：任意阶段都可一键回退到规则脑，回退不需要 Pro，不设障碍。
- **自动回退**：灰度/接管阶段，AI 连续失败 **5 次**（不可用、超时、连续异常）自动退回规则脑，无需人工干预。

## 2. 推荐操作流程

### 2.1 进入影子对比（rule → shadow）

1. 打开作战驾驶舱，下拉到「模型接管控制台」。
2. 确认当前为「规则脑」，点 **申请进入影子对比**。
3. 在待审批条上点 **同意并切换**。
4. 此后每个交易循环，AI 都会并行给出决策并写入影子记录，控制台"影子统计"开始累计样本。

> 影子模式不产生任何 AI 下单，只记录，风险为零，可长期开着观察。

### 2.2 达到灰度门槛（shadow → canary）

控制台"影子统计"展示：

- **影子样本数**：累计对比了多少个信号。
- **影子脑可用**：AI 服务当前是否健康可连通。
- **与规则脑一致率**：AI 与规则脑给出同向结论的比例。
- **规则脑 / 影子脑耗时 p50、p99**：决策延迟分位数（毫秒）。
- **灰度达标**：是否同时满足样本数与一致率门槛。

默认门槛（可在申请前调整）：

- 影子样本 **≥ 100**；
- 一致率 **≥ 60%**。

达标后：

1. 设置 **灰度比例**（默认 10%，建议从 5%~10% 起步）；
2. 设置 **AI 单票仓位上限**（默认 5%，即 AI 下的买单最多占总资产 5%，只收紧不放宽）；
3. 点 **申请灰度接管** → **同意并切换**。

> 灰度比例按"标的代码哈希"确定性分流：灰度 10% 时，约 10% 的票（固定那批）交给 AI，其余仍走规则脑。这样同一只票不会今天 AI、明天规则，便于对照。

### 2.3 全量接管（canary → live）

> 全量接管意味着 AI 会对**真实资金**自动下单，必须先完成实盘武装。

前置条件（后端强制校验，缺一即拒）：

- 券商通道为**真实通道且已武装**（见《真实通道上线手册》：单笔/单日限额、白名单、模拟演练、风险确认）；
- 灰度阶段已稳定运行一段时间（建议跨多个交易日、含涨跌不同行情）。

操作：点 **申请全量模型接管** → 二次确认实盘武装状态 → **同意并切换**。
进入 live 后控制台变为红色高危样式。

### 2.4 回退

- **人工**：任意阶段点右上 **一键回退规则脑**，立即恢复规则引擎全量决策。
- **自动**：AI 连续失败 5 次时系统自动回退，并记录原因；控制台显示"连续失败 n/5"。

## 3. 上线向导：先选对模式

控制台点「上线向导」，按风险从低到高三选一：

1. **模拟盘 · 零风险（推荐新手）**：模拟资金跑完整闭环，无需武装。
2. **半自动实盘 · 人在回路**：AI 出信号、你逐笔确认后下单；配合白名单、单笔/单日限额、武装闸门。
3. **全自动模型接管**：经影子、灰度后 AI 全量自动下单。

向导会要求你逐项完成前置检查（武装、风控参数、白名单、小资金、故障演练），未勾全无法进入下一步。**这些是自我确认清单，真正的武装/限额/白名单由后端闸门强制执行，不以前端勾选为准。**

## 4. 故障注入与急停演练（上线前必做）

控制台「故障注入 · 急停演练」点 **运行演练（5 项）**，系统会真实调用降级/保护路径并给出证据：

| 演练项 | 验证内容 |
| --- | --- |
| 模型超时 / 不可用 | 影子脑连不上时，健康检查失败自动降级规则脑，不卡住交易循环。 |
| 断网行情 / 模型不可达 | 规则脑只用本地特征，断网仍能给出决策（可安全暂停开新仓而非崩溃）。 |
| 交易客户端 / sidecar 崩溃 | 实盘未武装时，即使交易客户端崩溃，武装闸门保证不会发出真实委托。 |
| 行情陈旧 / 缺涨跌停价 | 缺快照或缺任一涨跌停价时，真实通道下单前一律拒绝（防乌龙指）。 |
| 一键急停 | 急停开关可立即置位（拦一切新委托）并复位，演练后不影响后续运行。 |

约束：

- 演练**只允许在模拟环境 / 实盘未武装时运行**；已武装实盘会直接拒绝，防止误触发真实通道。
- 演练结果写审计（`signal_audit`，action=`drill_run`）。
- 每次变更风控/通道配置、或准备提高灰度比例前，建议重跑一次。

---

## 5. 风控与急停

- **仓位收紧**：灰度/接管阶段 AI 执行的买入，单票仓位上限取 `min(原有上限, 小仓位上限)`，只收紧不放宽；硬止损与卖出不受小仓位限制（该止损时必须能全卖）。
- **账户级风控**：日亏止损、回撤保护、连续亏损保护沿用券商设置里的参数，AI 与规则脑一视同仁。
- **真实通道闸门**：白名单、单笔/单日限额、涨跌停快照、价格偏离、强制半自动（同花顺）等 P4 护栏对 AI 下单同样生效。
- **急停**：驾驶舱第 ⑤ 步「一键熔断」与控制台「一键回退」双入口；熔断拦截新委托，回退把决策权交还给规则脑。

---

## 6. 性能与审计口径

- 决策循环约每 5 秒一轮；影子模式每轮对每个信号额外做一次 AI 推理，失败按超时快速降级（健康检查约 800ms、决策约 1600ms 上限），不拖垮主循环。
- 控制台展示规则脑/影子脑决策耗时 p50、p99，目标单信号决策 <150ms（本地规则脑）；影子脑耗时取决于你的模型服务。
- 阶段切换（申请/审批/拒绝/回退）、演练结果均写 `signal_audit`，可在决策日志/审计中追溯。

## 7. 本轮交付边界（请务必了解）

本轮（P5）交付的是**完整的接管框架、灰度状态机、护栏、演练与前端**，以下依赖外部条件，属正常边界：

1. **模型服务（laya_sidecar）**：真正的 LightGBM/FastAPI 训练与推理服务本轮为框架预留。在你启动 sidecar 之前，影子脑不可用（影子记录 `shadow_ok=0`），系统会一直停留在"规则脑 + 攒框架"状态；启动 sidecar 后影子统计即开始累计真实样本。
2. **真机小额实盘**：依赖你在券商处开通 QMT 等量化权限（开通条件、资金门槛、费率**以券商为准**）。未开通前请在模拟盘完成影子对比与演练。
3. **云端 LLM 影子**：当前影子脑固定走 laya 模型通道，云端 LLM 暂未纳入影子对比。

## 8. 上线前检查清单

- [ ] 已在模拟盘跑通完整作战流，信号与成交符合预期。
- [ ] 已开启影子对比并积累达到门槛的样本，一致率可接受。
- [ ] 灰度比例从小值起步，AI 小仓位上限已设置。
- [ ] 故障演练 5 项全部通过。
- [ ] 券商设置：武装、单笔/单日限额、白名单、日亏/回撤/连亏保护已配置并复核。
- [ ] 已知道一键熔断与一键回退的位置，并实际演练过。
- [ ] 只用可承受亏损的自有资金，不借贷、不加杠杆。

> 风险提示：系统与模型仅为交易辅助，任何模型都无法保证盈利，历史表现不代表未来收益，最终交易决策与后果由使用者自行承担。
