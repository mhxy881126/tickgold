# 涨停雷达・「连板天梯」升级方案（对标同花顺，喂给打板选股器）

> 对标：同花顺「连板天梯」（左昨日高标 / 右今日晋级 / 右沿晋级率统计）。
> 原则：
>
> **优先用现成数据改前端，其次才动 Rust 推送结构**
>
> ；每一步升级同时就是打板选股器的因子底座。



***

## 一、同花顺连板天梯为什么专业（拆给我们自己看）



| 设计                                                     | 它解决了打板选手什么痛点                                           |
| ------------------------------------------------------ | ------------------------------------------------------ |
| **左「昨日高标」↔ 右「今日晋级」双栏对照**                               | 一眼看出昨天打的板今天活了几只、挂了几只 —— 复盘第一需求                         |
| 左栏每票直接显示**今日涨幅**：+9.99% 红 = 晋级涨停，-9.98% 绿 = 闷杀，-3%= 断板 | 不用点进去就知道这只昨天涨停今天什么下场                                   |
| 名称随状态**染色**（红 = 连板成功 / 绿 = 挂了 / 紫 = 选中）                | 状态扫一眼即得                                                |
| 最右沿**按板级晋级率 / 炸板率 / 竞价涨幅**，还带「五日平均」                    | 一眼判断 "今天做几板性价比最高"（截图里 2 板晋级率仅 12.77% 很差，3 板 57% 反而有活口） |
| **昨日涨停原因**列（题材 / 概念）                                   | 不用点 F10 就知道这票炒什么、有没有板块                                 |
| **换手 \[实] 列**                                          | 筹码结构，接力核心指标                                            |
| 顶部**主板 / 创业板 / 科创板 / 北交所**筛选                           | 只看自己能做的板块                                              |

## 三、升级方案（分三期，越前面越快）

### P0・纯前端立即可做（数据已有，只改渲染）

**1. 梯队 chip 信息密度升级**（现在：`传艺科技 16.90` → 改成）：



```
传艺科技  +9.99%  16.90  │ 首封9:42  封单2.3亿  换手18%
```



* 名称按今日状态染色：今日涨停 = 红、涨但未板 = 橙、跌 = 绿、平盘 = 灰

* 小字依次：今日涨幅 → 首封时间 → 封单额 → 换手率

* 2 板组以上的 chip 排两行，不挤

> pct 后端已推；首封 / 封单 / 换手从 
>
> `fetchZtPool(今日)`
>
>  按 code join 补上（涨停池接口现成）。

**2. 涨停原因标签**：chip 下方加一行小灰字题材（如 "固态电池"+2 只助攻），来自涨停池 industry / 题材库。一眼分清龙一还是跟风。

**3. 2 板 / 3 板组加 "选股" 角标**：在这两组标题旁加一个小漏斗图标，点击 = 把这组票一键送进选股引擎打分（直接接上一份《连板选股引擎》）。

### P1・新增「天梯」视图（核心新 Tab）—— 左右对照

雷达卡片 Tabs 从 `连板梯队/涨停/炸板/跌停` 扩一个 `天梯` Tab：



```
┌─────────────────────────────┬──────────────────────────┬──────────┐
│  昨日高标（57只）            │  今日晋级（12只）         │ 板级统计  │
│                             │                          │          │
│ 高度龙头1                   │ 高度龙头1                │ 晋级率    │
│  新华传媒 10.35 +9.99% 红    │  新华传媒 10.35 +9.99%   │  总21%↓  │
│                             │                          │  2板12%↓ │
│ 二连板7只：                 │ 三连板4只：              │  3板57%↑ │
│  深物业A 12.24 +9.97% 红✓   │  九阳股份 +10.04%        │  炸板率  │
│  津药药业 26.60 -3.04% 灰✗  │  时代万恒 +9.95%         │  总18%   │
│  中新赛克 26.60 -8.65% 绿✗  │  善水科技 +20.01%        │  竞价涨幅│
│  浙江新能 7.70  -5.75% 绿✗  │  深物业A +9.97%          │  总+1.6% │
│  善水科技 35.93 +20% 红✓     │                          │          │
│  九阳股份 12.50 +10% 红✓     │                          │ (五日均值)│
│  时代万恒 9.72 +9.95% 红✓   │                          │          │
└─────────────────────────────┴──────────────────────────┴──────────┘
```



* **左列数据源**：`fetchZtPool(昨日)`，按昨日 boards 分组（高度龙头 / N 板 / 首板）

* **每只叠今日实时行情**：拿今日全市场快照按 code join，算出 pct 和 "今天是否仍涨停"


  * 红底 / 红字 = 今天还涨停 = **晋级成功**（✓）

  * 绿字 = 今天跌了 = **断板 / 闷杀**（✗）

  * 灰 = 小涨小跌没板

* **右列**：今天仍在涨停池、且 boards 比昨天 +1 的票（晋级的）

* **最右统计列**：


  * 总晋级率 = 今日晋级数 / 昨日涨停总数

  * 按板级：昨日 N 板今天成功 N+1 板的比例

  * 炸板率（已有 brokenRate）

  * 竞价涨幅（集合竞价面板已有，接入）

  * 五日均值 → 需要每日收盘把 "昨日涨停今日表现" 落库 SQLite，积累后自动算（首次上线为空，标注 "积累中"）

> 技术上全部前端可组装：昨日涨停池 (已有) + 今日实时快照 (已有 quotes) + 本地 join，
>
> **Rust 端几乎不用动**
>
> 。

### P2・筛选 + 与选股器打通



* 顶部加板块筛选：主板 / 创业板 (30) / 科创板 (688) / 北交所 (8/4)，勾选过滤梯队与天梯

* 天梯视图里，任何一只票右键 → "加入明日候选" / "按 2 进 3 战法打分"

* 统计列点某板级 → 自动筛出 "昨日该板、今日未晋级" 的票，作为反例样本

## 四、为什么这套升级 = 选股器的数据底座



| 同花顺 / 升级项                 | 在选股引擎里是哪个因子                       |
| ------------------------- | --------------------------------- |
| 左右对照 "昨日→今日晋级"            | **环境因子**：晋级率低于阈值就整体降仓 / 空仓        |
| 板级晋级率（2 板 12% vs 3 板 57%） | **板位选择**：自动提示 "今天做 3 板不做 2 板"     |
| 涨停原因 / 题材列                | **题材地位因子**：龙一 / 助攻 / 孤板判定         |
| 换手列                       | **筹码结构因子**：10\~25% 健康区间           |
| 封单额 / 首封时间                | **封板质量因子**（P0 chip 已展示）           |
| 板块筛选                      | 排除条件（688 / 创业 20cm 与主板 10cm 战法不同） |

也就是说：**先把雷达升级成同花顺那样 "看得懂"，选股引擎只是在同一份数据上再加一层权重排序**，界面壳子都能复用天梯视图。



***

## 五、建议落地顺序



1. **P0（当天能改完）**：梯队 chip 补 pct 染色 + 封单 / 首封 / 换手 + 题材标签 —— 立刻好用，纯前端。

2. **P1（1\~2 天）**：新增「天梯」Tab，左右对照 + 板级晋级率统计 —— 这是本次对标同花顺的核心，也是打板复盘刚需。

3. **P2（随选股引擎一起）**：板块筛选 + 一键送候选池。

4. 五日均值等历史指标：上线即开始每日落库，2\~3 周后自然变完整。

> ⚠️ 所有涨跌 / 晋级数据仅为盘面复盘与规则参考，不构成投资建议。
