# TickGold・连板接力选股引擎（打板战法选股器）功能需求

> 目标：把「昨日 N 连板 → 量化打分 → 今日候选 Top2 → 博次日冲高溢价」这套主观打法，
> 做成一个
>
> **可解释、可回测、可配置、自动出信号**
>
> 的选股模块，并把它推广到所有主流打板战法。
> 基线：现有 ZtStock 已采集 
>
> `封单金额fund / 连板数boards / 首封firstSeal / 最后封板lastSeal /`
> `炸板次数broken / 换手turnover / 行业industry / N天M板statDays,statCount / 成交额amount`
>
> ，
> 另有集合竞价面板、题材库（龙一 / 题材阶段）、情绪温度、龙虎榜席位、回灌打标框架。
> **本需求不新增行情接口，主要是把已有数据 "评分化 + 闭环化"。**



***

## 0. 先对齐你的战法：「2 板选 2 只博溢价」到底是什么



| 环节      | 时点               | 动作                                 | 系统对应                             |
| ------- | ---------------- | ---------------------------------- | -------------------------------- |
| 选股池     | T 日收盘后           | 取 T 日全部 **2 连板**                   | `fetchZtPool(T日)` 过滤 `boards==2` |
| 初筛      | T 日收盘后           | 按封单 / 封板时间 / 换手 / 题材 / 环境打分，留 TopN | **本引擎核心（新增）**                    |
| 上车      | T+1 竞价（9:25）/ 早盘 | 用竞价数据二次确认，符合条件才上车                  | 集合竞价面板联动（已有）                     |
| 持有 / 卖出 | T+1 \~ T+2       | T+1 涨停则持有，不板冲高走；T+2 不连板走           | 快脑卖出因子 + 信号桥（已有）                 |
| 复盘      | T+3 起            | 自动记录这笔 "如果买了" 的真实收益                | 回灌打标框架（已有，复用）                    |

**这本质是「2 进 3 接力 + 竞价确认」。** 你截图里那 6 只 2 板（传艺科技 / 紫竹高科 / 同兴股份 / 上海洗霸 / 亚邦股份 / 均瑶健康），

现在界面只显示了 "名称 + 现价"，**封单额、首封时间、炸板次数、换手、题材、竞价这些决定生死的因子一个都没展开**——

这就是为什么现在 "看着一堆票却不知道选哪只"。引擎要做的就是把这些因子自动算成一个分。

## 2. 核心模块：连板选股引擎（StocksSieve）

### 2.1 输入



* **板级筛选**：首板 / 1 进 2 / 2 进 3 / 3 进 4 / 高位（≥4 板最高标）/ 全部

* **战法模板**：下拉选（见第 3 节），不同模板 = 不同因子权重 + 不同排除条件

* **市场环境开关**：情绪亢奋 / 震荡 / 冰点，引擎据此自动调整 "敢做高位还是只做低位"

### 2.2 因子库（每个因子 = 方向 + 阈值 + 权重 + 数据来源）

> 权重做成可调，默认值是短线圈共识，上线后用历史回测校准。

**A. 封板质量（决定当天强不强）**



| 因子             | 方向      | 默认口径                                   | 数据来源                  |
| -------------- | ------- | -------------------------------------- | --------------------- |
| 首封时间 firstSeal | 越早分越高   | 10:00 前 = 满分，午后板大幅扣分，尾盘 (14:30 后) 直接排除 | ZtStock.firstSeal ✅   |
| 炸板次数 broken    | 越少越好    | 0 次满分，≥2 次大幅扣分，≥3 次排除                  | ZtStock.broken ✅      |
| 封单强度 fund      | 越大越好    | 封单额 / 当日成交额 比值 ≥5% 满分                  | ZtStock.fund/amount ✅ |
| 最后封板 lastSeal  | 回封越果断越好 | 一次封死 > 反复回封                            | ZtStock.lastSeal ✅    |

**B. 筹码结构（决定次日有没有人接力）**



| 因子           | 方向        | 默认口径                                       | 数据来源               |
| ------------ | --------- | ------------------------------------------ | ------------------ |
| 换手率 turnover | 适度最好      | 10%\~25% 健康；<5% 一字无量（接力砸盘风险）扣分；>35% 过度分歧扣分 | ZtStock.turnover ✅ |
| 流通市值         | 小票弹性大     | 30 亿～150 亿情绪票最佳；>300 亿权重股不适合连板接力           | **需补流通市值**         |
| 股价位置         | 低位首接 > 高位 | 2 板阶段看是否已在历史高位、是否累计涨幅过大                    | K 线已有 ✅            |

**C. 题材地位（决定是不是真龙）**



| 因子      | 方向           | 默认口径             | 数据来源    |
| ------- | ------------ | ---------------- | ------- |
| 题材角色    | 龙一 > 龙二 > 跟风 | 题材库已有龙一 / 龙二评分   | 题材库 ✅   |
| 题材阶段    | 发酵 / 高潮 > 退潮 | 退潮期不接力           | 题材库 ✅   |
| 题材梯队完整性 | 有助攻 > 孤板     | 同题材今天还有几只涨停、梯队几层 | 涨停池聚类 ✅ |
| 是否独立孤板  | 有板块效应加分      | 无任何同板块助攻 → 排除    | 涨停池聚类 ✅ |

**D. 资金与席位（决定有没有人抬轿）**



| 因子        | 方向                                                 | 数据来源     |
| --------- | -------------------------------------------------- | -------- |
| 主力净流入     | 红盘流入加分                                             | 个股资金流 ✅  |
| 龙虎榜知名席位   | 章盟主 / 炒股养家等净买入加分；拉萨天团 (散户集中营) 减分                   | 龙虎榜 ✅    |
| 竞价量比（T+1） | 高开 2%\~6% + 竞价额放大 1.5 倍以上 = 强确认；低开 / 巨量高开 7%+ = 慎入 | 集合竞价面板 ✅ |

**E. 市场环境（决定今天该不该出手）**



| 因子          | 口径                                              | 数据来源           |
| ----------- | ----------------------------------------------- | -------------- |
| 情绪温度        | 亢奋 (≥80) 可做高位；冰点 (<30) 只做首板 / 空仓                | 雷达 ✅           |
| 昨日 2 板今日晋级率 | 昨天 N 只 2 板，今天几只成功 3 板 —— 晋级率 < 40% 说明接力环境差，整体降仓 | **需自建历史涨停池快照** |
| 炸板率         | >30% 说明封板不稳，降低出手仓位                              | 雷达 ✅           |
| 最高标高度       | 最高板在抬升 = 情绪向上；最高板断板闷杀 = 退潮信号                    | 雷达 ✅           |

### 2.3 输出



* 每只候选票：**总分（0\~100）+ 分项得分条 + 命中的加分项 + 被排除 / 扣分的原因**

* TopN 默认 5 只，前 2 只金色高亮（对应你 "选 2 只"）

* 每只可点开：K 线 + 五档 + 题材 + 龙虎榜联动（复用现有联动）

* **明确标注**：本结果为规则筛选与概率参考，非投资建议

### 2.4 硬性排除规则（一票否决，不参与打分）

ST/\*ST、一字板（全天无换手）、尾盘偷袭板（14:30 后首封）、上市次新无历史、当日有大额解禁、

无板块效应的独立涨停、已被监管点名异动。

>
> `strategy_profile`
>
>  表）。

| --------------- | ---------------- | ------------------- | ------------- | ------- | -------------- | -------------- |
| `promotion2to3` | **2 进 3（你的主战法）** | T 日 2 板             | T+1 竞价确认后上车   | 1\~2 日  | 不板冲高走 / 破分时均线走 | 情绪平稳偏强         |

## 4. 闭环：从 "出候选" 到 "验证灵不灵"



1. **盘后自动出票（15:30 后）**：收盘涨停定格后，自动跑当日 "2 板池" 打分，生成「明日候选 Top5」写入本地，推送到灵动岛。

2. **竞价二次确认（次日 9:25）**：用竞价高开幅度 / 竞价额对候选池再过滤一遍 —— 昨天打分高但今天低开闷杀的，直接剔除并标 "弃"；竞价超预期的，标 "强确认"。

3. **一键进作战计划**：候选票一键加入次日作战计划（现有功能），自动映射成预警。

4. **自动打标回测（T+3\~T+5）**：复用现有回灌框架，记录 "如果按此模板在 T+1 上车" 的真实：次日最高价 / 收盘涨幅 / 2 日涨幅 / 是否冲高止盈，统计每个模板近 N 个月的**胜率、平均冲高幅度、盈亏比**—— 让数据告诉你哪套战法、哪套权重在当下市场最赚钱。

5. **权重自校准建议**：回测发现 "首封时间" 因子区分度高、"换手" 因子在当前行情无效时，给用户调权建议（人工确认，不自动改）。

## 6. 交付形态：新卡片「连板选股器」



* **顶部**：战法模板下拉（2 进 3 默认）+ 板级筛选 + 环境显示（亢奋 / 震荡 / 冰点）+ 日期选择

* **中部表格**：候选票列表，列 = 总分 / 名称 / 现价 / 封单额 / 首封时间 / 炸板 / 换手 / 题材角色 / 竞价状态，按总分排序，Top2 金色描边

* **行展开**：左侧大列表，右侧滑出**分项打分条**（每个因子加分 / 扣分可视化）+ 排除原因 + 一句话评语（AI / 规则生成）

* **底部操作**：「加入明日作战计划」「转预警」「导出 CSV」「查看本模板历史回测」

* **联动**：点任意票 → K 线 / 盘口 / 题材档案联动（复用现有联动机制）

* 挂在「交易工具 / 条件选股」域下，命令面板 `Ctrl+K` 可搜 "选股 / 打板 / 接力" 打开
