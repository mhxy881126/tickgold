## 1. 作战台（P0/P1）
1. 打开「今日作战流」卡片。
   - 预期：时间轴 6 段、当前时段高亮、倒计时每秒走；右上角「旧版六步」可切换。
2. 点时间轴任一阶段。
   - 预期：面板切换为该阶段清单，不改变当前状态；再点「现在」恢复。
3. 下单条输入 `600519`。
   - 预期：名称/现价回填，五档与涨跌停价出现；点「买入」弹出一次确认（金额/账户类型）。

## 2. 条件单触发（P1）
1. 用 Copilot 输入 `600519 跌破1680 买入100股` → 解析 → 创建条件单。
   - 预期：「本地条件单」出现一条 active，触发价 1680，方向 BUY，数量 100。
2. 把触发价改到现价上方（如现价 1700 → 改成 1705）保存。
   - 预期：旧单取消、新单建立；下一个 5s tick 内触发。
3. 等 5–10s，看作战台指令列表/信号桥。
   - 预期：状态「已触发」→ 模拟盘自动「已下单/已成交」；若关闭「模拟自动」，应停在待确认。
4. 急停（Ctrl+Alt+K 或界面按钮）。
   - 预期：全部条件单撤销、关联指令「已放弃」；30s 内不会被重新物化。
