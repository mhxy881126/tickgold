# 同花顺客户端真机校准手册（TickGold・同花顺控制台）

> 适用版本：TickGold v3.4 起，「同花顺控制台」卡片（卡片 id：
>
> `brokerconsole`
>
> ）。
> 本功能把开源项目 THSAutoTrader 的同花顺 GUI 自动化（键盘精灵闪电下单、剪贴板读表、验证码 OCR、
> 全撤 / 撤买 / 撤卖、仓位下单、进程窗口探测）融入 TickGold，走 
>
> **stdio NDJSON 单 sidecar**
>
> ，不另起端口 / 服务。
> **重要边界**
>
> ：本程序只模拟 “人在键盘鼠标上的操作”，不破解、不注入、不修改同花顺客户端，
> 合规风险与你手动下单一致；但自动化下单的市场风险由你自己承担，请务必先用 dry-run 与模拟盘跑通。



***

## 一、它能做什么（点一下就跑）

在工作台「添加卡片 → 交易工具 → 同花顺控制台」打开一张卡，连上通道后：



| 区块       | 功能                                     | 说明                    |
| -------- | -------------------------------------- | --------------------- |
| 顶部状态     | 连接状态 / 模拟盘・真实盘 / 探测客户端 / 刷新            | 探测会检查同花顺下单程序进程与前台窗口   |
| 资金四格     | 总资产 / 可用资金 / 持仓市值 / 当日盈亏               | 每 6 秒自动刷新             |
| 持仓       | 代码、名称、持仓、可用、成本、现价、市值、盈亏                | 点「持仓」Tab              |
| 当日成交     | 时间、代码、方向、价格、数量、状态                      | 点「当日成交」Tab，剪贴板读表      |
| 当日挂单     | 委托、已成、方向、价格、状态 + 撤买 / 撤卖 / 全撤          | 点「当日挂单」Tab，右上角一键撤单    |
| 仓位下单     | 买入 / 卖出 + 代码 + 参考价 + 全 / 半 / 1/3/1/4 仓 | 按可用资金自动换算股数，键盘精灵填单    |
| 高级调试（折叠） | 发送键盘序列、点击坐标                            | 仅真机校准用，默认隐藏           |
| 验证码弹窗    | 复制表格遇验证码时弹图、人工输入                       | 配了 Tesseract 会先自动 OCR |
| 撤单核对     | 真实通道撤单前截图核对                            | 核对无误才在客户端落键           |

## 二、运行环境准备（仅 Windows，真实模式才需要）



1. **Python 3.10–3.12**（安装时勾选 Add to PATH）。在「设置 → 券商交易 → 同花顺客户端参数 → Python 路径」

   填写 `python.exe` 完整路径（留空则用系统默认 `python`）。

2. **依赖包**（真实模式；dry-run 不需要）：



```
pip install pywinauto pywin32 psutil pyautogui pillow pytesseract
```



1. **同花顺网上股票交易系统 5.0**（券商通用下单程序，独立于行情客户端）。

* 先手动登录一次，确认能正常弹出标题为「网上股票交易系统 5.0」的下单窗口；

* 「同花顺客户端路径」可留空（自动按窗口标题 / 进程探测），探测不到再填 `xiadan.exe` 或模拟炒股可执行文件路径。

1. **Tesseract OCR（可选）**：用于复制表格时自动识别验证码。

* 安装 Windows 版 Tesseract（识别中文交易程序里的数字验证码即可，可只装英文 / 数字语言包）；

* 在「设置 → 券商交易 → Tesseract OCR 路径」填 `tesseract.exe` 完整路径；

* 不装也能用：识别失败时控制台会弹出验证码图片，由你手动输入。

## 三、三档环境（强烈建议按顺序逐级切换）



1. **dry-run 空跑（默认，最安全）**

* 「设置 → 券商交易」选择同花顺客户端通道，保持「dry-run 空跑」开启；

* sidecar 内置虚拟账户，全程**不启动、不操控**同花顺，可离线演练四表、仓位下单、撤单、验证码全部流程；

* 用于确认界面、事件链路、参数正确。

1. **模拟炒股（同花顺模拟盘）**

* 关闭 dry-run、保持「模拟交易（虚拟资金）」开启；

* 此时会真实操控同花顺的**模拟炒股**客户端，但不碰真钱，用来校准键盘精灵与控件 ID；

* 建议保持「自动确认」关闭，每笔下单前弹截图核对，确认无误再放全自动。

1. **真实账户（真实资金）**

* 关闭模拟交易，按 P4 上线流程**完成武装**：单笔限额、单日限额、白名单、价格偏离、模拟演练；

* 真实资金下**强制半自动**：每笔下单 / 撤单都先截图、红色确认桥由你核对，系统不会替你点 “确定”；

* 白名单外代码、超限额、价格偏离过大的委托会被直接拦截。

## 五、真机校准方法（控件 ID 对不上时）



1. 用微软 **Inspect**（Windows SDK 自带，`inspect.exe`）或 **Accessibility Insights for Windows**，

   以 UIA 模式查看同花顺下单窗口。

2. 鼠标悬停目标控件，读取其 `AutomationId`（即控件数字 ID）与 `ControlType` / `ClassName`。

3. 对照上表：

* 下单流程点不到 → 核对 `1034`（数量）、`1006`（确认）、`#32770`（确认弹窗）；

* 仓位按钮错位 → 核对 `12092~12095`；

* 撤单失效 → 核对 `30001/30002/30003`；

* 资金读错 → 核对 `1012~1029`；

* 表格读不到 → 核对 `1047`（表格内容区），Ctrl+C 后在剪贴板里应能粘贴出 TSV 表格；

* 验证码异常 → 核对 `2405/2404/2406/1/2`。

1. 用控制台「高级调试」做**单点验证**：

* 「发送键盘序列」填 `F4`（打开资金页）等，验证键盘精灵通路；

* 「点击坐标」填 Inspect 读到的客户区坐标，验证点击通路；

* 两个操作都在 GUI 互斥锁内串行执行（30 秒抢不到锁会返回 busy）。

1. 改完常量后，无需重新打包 Rust：`sidecar_client.py` 是 Tauri 资源文件，

   开发态直接保存生效；正式发版由构建流程重新打包（`tauri.conf.json` 显式打包该单文件）。

> 表格表头文案差异（如 “股票余额 / 可用余额”“委托数量 / 成交数量”）已由 
>
> `sidecar_client.py`
> 的中文字段别名兼容；若新版本改了表头，在对应 
>
> `normalize_*`
>
>  函数的别名表里补一列即可。

## 六、常见故障排查



| 现象                 | 排查方向                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| 连接后 “客户端未连接”       | 确认 Python 路径与依赖；看「探测客户端」结果；真实模式需先登录下单程序                                |
| 探测显示 “未运行 / 未找到窗口” | 下单窗口标题不是「网上股票交易系统 5.0」；用 Inspect 看真实标题，必要时调整 `MAIN_TITLE` / `title_re` |
| 下单键盘精灵没反应          | 同花顺焦点不在下单窗口；先用高级调试发 `F4` 验证；确认 `#32770` 确认弹窗 ID 未变                     |
| 成交 / 挂单 / 持仓读不到    | 表格区 `1047` 变更或 Ctrl+C 被禁用；手动在表格里 Ctrl+C 看剪贴板，再校准 `CID_LIST`            |
| 验证码一直弹             | 未装 Tesseract 或路径不对；可直接在弹窗人工输入，不影响后续流程                                  |
| 验证码输错              | 程序会检测 `2406` 错误提示并重新弹图，重新输入即可                                          |
| 撤单没生效              | 核对 `30001/30002/30003`；真实通道必须在撤单核对弹窗点 “确认撤单” 才落键                       |
| 返回 busy / 429      | 上一个 GUI 动作还没结束（互斥锁 30 秒）；等几秒再试，勿连点                                     |
| 委托被拦截              | 命中白名单 / 单笔限额 / 单日限额 / 价格偏离护栏；按提示到「上线向导」调整（真实通道需重新武装）                   |

## 七、安全与合规



* 真实资金**默认锁定**：未武装、未关模拟盘、未通过演练时不允许真实下单。

* 每笔真实委托都经过：白名单 → 单笔限额 → 单日累计 → 价格偏离 闸门，且在 **Python 侧独立兜底**

  （即使上层 UI 出错，sidecar 也会再拦一次）。

* 真实通道强制半自动截图确认；「自动确认（全自动）」仅允许在模拟环境开启。

* 本程序不存储券商交易密码、不绕过同花顺登录与风控；所有操作等同于人工操作。

* 请遵守所在券商自动化交易相关条款与市场监管规定，量力而行。

## 九、HTTP API 服务（THSAutoTrader 兼容接口）

连接通道后，sidecar 可在本机开放 REST 接口（仅监听 `127.0.0.1`），供脚本 / 外部平台 / Excel 宏调用下单与查询，**与界面操作走同一套引擎、同一把互斥锁、同一套风控闸门**，不绕过任何护栏。

### 9.1 开启方式（点一下就跑）

1. 设置 → 券商交易 → 同花顺客户端 → 「HTTP API 服务」区块：打开「启用 API 服务」（默认端口 5000）。
2. 可留空「访问令牌」（本机免密），或设置一个（之后请求需带 `?token=` 或 `Authorization: Bearer`）。
3. 保存配置 → 连接通道，sidecar 即带 HTTP 服务启动。
4. 打开「同花顺控制台」→「API 控制台」页签：顶部状态灯变绿即服务就绪，每个接口可一键调用并看 JSON 返回。

### 9.2 接口一览（12 个）

| 接口 | 参数 | 说明 |
|---|---|---|
| `GET /health` | — | 服务存活探测 |
| `GET /check_trading_app` | — | 同花顺下单程序进程探测 |
| `GET /current_page` | — | 当前前台窗口信息（句柄/标题） |
| `GET /balance` | — | 账户资金：现金 / 市值 / 总资产 / 盈亏 |
| `GET /position` | — | 持仓列表 |
| `GET /today_trades` | — | 当日成交流水 |
| `GET /pending_orders` | — | 当日挂单（未成交委托） |
| `GET /xiadan` | `code=600519` `status=1\|2`（1买2卖） `amount=100`（可选） `price=10.5`（可选） | 闪电下单（THSAutoTrader 同款） |
| `GET /confirm_order` | `position=1\|2\|3\|4`（全/半/1/3/1/4 仓） | 用最近一次 /xiadan 上下文按仓位下单 |
| `GET /cancel_all_orders` | `type=A\|X\|C`（全撤/撤买/撤卖） | 一键撤单 |
| `GET /send_key` | `key=600519 ENTER 21 ENTER` | 键盘精灵（向同花顺窗口发键） |
| `GET /click` | `x=100` `y=200` | 客户区相对坐标点击 |

### 9.3 curl 示例

```bash
# 查资金
curl "http://127.0.0.1:5000/balance"
# 买 100 股浦发银行（模拟盘；真实通道须先武装 + 白名单 + 半自动截图确认）
curl "http://127.0.0.1:5000/xiadan?code=600000&status=1&amount=100&price=10.5"
# 半自动模式秒回「等待人工确认」，再到确认桥核对截图后放行
# 设了令牌时追加 ?token=你的令牌
```

### 9.4 返回约定

* 成功：`{"status": "success", "message": ..., "data": ...}`；失败：`{"status": "error", "message": ...}`（HTTP 200）。
* 令牌错误：HTTP `401`；GUI 操作繁忙：HTTP 200 + `{"status": "busy"}`。
* 下单类不绕过风控：未连接 / 白名单外 / 超限额 / 半自动未确认时返回明确错误，与界面一致。
* 同一时刻只处理一个 API 请求（与窗口操作互斥），避免 GUI 自动化并发冲突。

### 9.5 安全说明

* 仅绑定 `127.0.0.1`，不对外网开放；令牌可选、默认免密（本机）。
* API 与界面共用引擎与护栏：真实通道强制半自动截图确认，白名单/限额/Python 侧兜底全部生效。
* 不要把令牌写进分享出去的脚本 / 聊天记录；本机使用可留空。
