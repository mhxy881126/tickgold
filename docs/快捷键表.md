# 键盘快捷键

应用内可随时按 `Ctrl/⌘ + /`（或在非输入状态下单按 `?`）打开快捷键速查面板。本页内容与面板一致。

> macOS 下 **Ctrl** 对应 **⌘（Command）**。

## 全局 / 窗口

| 快捷键 | 功能 |
| --- | --- |
| `Alt + ` `（反引号） | 显示 / 隐藏窗口（老板键） |
| `Ctrl/⌘ + K` | 打开命令面板 |
| `Ctrl/⌘ + ,` | 打开设置 |
| `Ctrl/⌘ + U` | 检查更新 |
| `Ctrl/⌘ + /` | 打开快捷键速查 |

## 命令面板

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 移动选择 |
| `Enter` | 打开所选功能 |
| `Esc` | 关闭面板 |

## 通用

| 快捷键 | 功能 |
| --- | --- |
| `Esc` | 退出卡片聚焦 / 关闭弹窗 |

## K 线 / 复盘

| 操作 | 功能 |
| --- | --- |
| 双击蜡烛 | 打开历史分时复盘工作台 |
| `Esc` | 结束画线 / 关闭弹窗 |

## 使用提示

- 单键（如 `?`）仅在焦点**不在输入框 / 文本域**时生效，避免与正常输入冲突；
- 中文输入法可能拦截逗号等按键，使用 `Ctrl + ,` 前建议切到英文输入法；
- 若希望调整或扩展快捷键，可在 `src/App.vue` 的 `onGlobalKey` 中修改，并同步更新应用内速查面板（`src/components/ShortcutDialog.vue`）与本页。
