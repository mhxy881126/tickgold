# 常见问题 FAQ

**安装与卸载**

### Windows 双击安装包提示「已保护你的电脑」？

安装包暂未做代码签名，SmartScreen 会拦截。点击「更多信息 → 仍要运行」即可。本项目开源，可自行从源码审计与构建。

### 可以直接覆盖安装升级吗？

可以。运行新版安装包即可，安装器会自动结束正在运行的 TickGold（含 WebView2、托盘进程）并等待文件释放，无需先卸载。若曾以管理员身份运行过，请先从托盘右键完全退出再安装。

### 卸载会删掉我的自选股吗？

卸载结束时会弹窗询问：选「是」删除个人数据，选「否」（默认）保留。静默卸载默认保留数据。

### macOS 提示「无法打开 / 无法验证开发者」？

到「系统设置 → 隐私与安全性」中点击「仍要打开」；或在应用上右键 → 打开。Apple 芯片请下载 `aarch64`，Intel 芯片下载 `x64`。

**数据与备份**

### 我的数据保存在哪里？

Windows 在 `%APPDATA%\com.stockdock.desktop`，核心是 `stock-dock.db`。详见[用户手册 · 数据与隐私](用户手册.md#十一数据与隐私)。

### 如何备份 / 迁移到新电脑？

复制 `stock-dock.db` 到新电脑对应数据目录即可。应用在每次更新前也会自动备份到 `backups\`（保留最近 5 个）。

### 启动后提示 / 自动恢复数据库？

若数据库损坏，应用会把损坏文件重命名留证、自动恢复最近备份并重启；若没有任何备份，则会提示错误，需要从你自己的备份还原。

**行情与使用**

### 行情不刷新 / 数据有延迟？

TickGold 使用公开免费行情接口，不保证实时性。可检查网络连接；应用在断网后会自动重连续传。非交易时段显示「非交易时段」属正常。

### 为什么复盘没有历史五档盘口 / 9:25 竞价点？

免费行情源不提供历史五档与集合竞价分钟数据，复盘以该分钟价格、均价、成交量与涨跌幅为准。

### 支持真实下单 / 手机版 / Linux 吗？

不提供真实委托下单（需券商资质），仅有模拟交易；目前发布 Windows 与 macOS 桌面版。

**界面与快捷键**

### 灵动岛悬浮条是什么？如何隐藏 / 呼出？

灵动岛是常驻顶部的迷你行情条。按 `Alt + ` `（反引号）可快速显示 / 隐藏整个窗口（老板键）。

### 开机自启不生效？

在「设置 → 外观」中确认「开机自动启动」已开启；Windows 写入注册表 Run 项、macOS 使用 LaunchAgent，若被安全软件拦截请检查相关设置。

### 如何查看全部快捷键？

按 `Ctrl/⌘ + /`，或在非输入状态下单按 `?`。完整列表见[键盘快捷键](快捷键表.md)。

### 按 `Ctrl + ,` 打不开设置？

若处于中文输入法，逗号键可能被输入法拦截，请先切换到英文输入法，或直接点击顶栏「设置」。

**更新**

### 更新失败 / 下载很慢怎么办？

更新检查与下载已内置多镜像容灾，会自动重试；仍失败时可在更新对话框点击「手动下载」，到 Releases 页面下载安装包覆盖安装。
