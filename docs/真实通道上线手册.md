# TickGold 真实通道上线手册（P4）

> 适用版本：v3.1.1（P4 真实通道安全护栏）
> 通道路线：**QMT 官方接口为主，同花顺 GUI 自动化为备选；真实盘首版强制半自动（每笔人工确认）。**
> 安全原则：**真实通道出厂即锁、纵深防御、fail-safe**。未完成武装向导前，程序不会提交任何真实委托。

---

## 1. 安全总览：三道防线

真实资金下单链路在三个相互独立的层面各设一道闸门，任何一层被绕过或异常，都不会把委托发到交易所：

| 层级 | 位置 | 作用 |
| --- | --- | --- |
| 第一道 · Rust 核心 | `broker::submit_with_sig` | 武装校验 + 白名单 + 强制涨跌停快照 + 单笔/单日限额 + 强制半自动 |
| 第二道 · Python sidecar | `sidecar_qmt.py` / `sidecar_client.py` | 独立白名单/单笔/单日兜底；同花顺真实模式强制忽略自动确认、账户类型交叉校验 |
| 第三道 · 人工确认 | 确认桥 / QMT 二次弹窗 | 每笔真实委托必须人工核对后点击确认（首版不允许无人值守） |

- 真实通道（`is_live()`）：**QMT**，或**同花顺客户端的真实账户**（关闭「模拟交易」）。
- 模拟通道：内置 mock、同花顺「模拟炒股」（虚拟资金），不受实盘护栏约束，也不会提交真实委托。

**fail-safe 设计**

- 真实通道下，若实时行情拿不到涨跌停价，一律拒绝下单（防止价格数量级乌龙指）。
- QMT sidecar 若未下发白名单/单笔限额，拒绝一切下单。
- 同花顺真实模式无论是否传入「自动确认」，sidecar 一律强制半自动。
- 武装后任何安全参数（通道、单笔/单日限额、白名单、模拟演练标记）被改动，**自动解除武装**，必须重新走武装向导。

## 2. 出厂状态（默认全部锁定）

初次安装 / 未武装时，真实通道相关配置为：

- 实盘开关：关闭；武装时间：0（未武装）
- 单笔金额上限：`0`（=锁定）
- 单日累计买入上限：`0`（=锁定）
- 实盘白名单：空（=全部禁止）
- 同花顺模拟演练标记：未通过
- 同花顺通道默认：模拟交易 `开`、dry-run `开`（虚拟资金，不碰真钱）

在这种状态下，即使误触「发送」，真实委托也会被第一道闸门拒绝。

## 3. 通道 A：QMT / miniQMT（推荐，官方接口）

### 3.1 开通条件

1. 券商支持 QMT（迅投）并为你开通 **miniQMT / 量化交易权限**。
2. 资金门槛与开通材料**因券商而异**（常见为几十万元，也有券商更低或免费），**请以你的券商客户经理给出的最新条件为准**。
3. 安装券商提供的 QMT 客户端（含 xtquant），登录后以**极简模式**运行（miniQMT 供第三方调用）。

> 本软件不替你向券商申请权限，也不提供任何券商账号；请自行完成开通。

### 3.2 本地准备

- Python 3.8–3.12（建议 3.10/3.11），并能导入 QMT 自带的 `xtquant`。
- 在 设置 → 券商交易 中选择「QMT 实盘」，填写：
  - Python 路径（已装 xtquant 的解释器）
  - miniQMT `userdata_mini` 路径
  - 资金账号

### 3.3 连接自检

- 点击「连接」，程序通过 `sidecar_qmt.py` 启动 xtquant 并订阅账号。
- 连接成功后资产/持仓会回报到工作台；连接失败按提示检查 QMT 是否极简模式登录。

## 4. 通道 B：同花顺 GUI 自动化（备选，真实客户端）

> 原理：无公开交易 API，通过 Python（pywinauto/pyautogui）操控同花顺下单窗口。
> **GUI 自动化天然脆弱**（窗口版本、控件位置、弹窗都会影响），因此必须先在模拟盘完成真机演练。

### 4.1 合规与风险提示

- 自动化操控券商客户端可能受券商客户端协议、券商风控规则约束；**请先确认你的券商允许此类操作，风险自担**。
- 本通道属于程序化交易，须履行程序化交易报告义务（见第 7 节）。
- 控件定位在不同券商/版本上不同，首次必须录制 `selectors.json`（方法见《同花顺模拟通道·真机联调手册.md》）。

### 4.2 环境准备

- Python 3.10–3.12：`pip install pywinauto pyautogui pillow`
- 真实同花顺交易客户端（非模拟）可执行文件路径（如 `xiadan.exe`），保持登录。

### 4.3 强制模拟演练（武装前置）

在武装真实通道前，**必须**先在同花顺「模拟炒股」中完成真机演练并确认：

1. 选择「同花顺」通道，打开「模拟交易」（client_sim=true），连接自检通过。
2. 半自动模式下，连续成功若干笔：填单、截图核对、确认、撤单、资产/持仓回报均正常。
3. 演练通过后，在真实通道武装向导中勾选「我已完成模拟演练」（该标记写入审计）。

连接时 sidecar 会按窗口标题交叉校验：**模拟配置连到真实窗口、或真实配置连到模拟窗口，都会被拒绝**，防止误操作真钱。

## 5. 武装 checklist（武装向导 5 步）

进入 设置 → 券商交易，选择真实通道（QMT 或同花顺真实账户），「实盘委托」区会显示红色高危武装向导。逐项完成：

1. **单笔金额上限**：单笔委托金额（价格×数量）超过即拒，`0` = 锁定。
2. **单日累计买入上限**：当日真实买入累计（不含已撤/已拒）超过即拒，次日重置；须 ≥ 单笔上限。
3. **标的白名单**：至少 1 只 6 位代码；真实通道仅允许白名单内标的。
4. **（仅同花顺）模拟演练**：勾选已完成真机演练；真实通道自动确认永久禁用。
5. **风险告知**：阅读风险告知与程序化交易报告提示，在输入框输入「**风险确认**」四个字。

点击「武装实盘」，后端会再次校验全部前置条件，任一不满足都会拒绝并提示原因。武装成功后：

- 状态条变红「实盘已武装」，显示今日已用买入 / 剩余额度 / 单日上限 / 白名单数量。
- 武装/解除动作写入审计日志（`LIVE-ARM`）。

> 限额建议：首周用你能承受全部亏损的最小额度试水（例如单笔 5 千–1 万、单日 2 万–5 万），跑稳后再逐步放大。

## 6. 半自动下单流程

### QMT
信号确认桥点击「实盘发送」→ 弹出**真实资金二次确认**（显示代码、数量、参考金额、护栏提示）→ 确认后提交。
护栏在提交前由 Rust + sidecar 双重校验，越界立即拒绝。

### 同花顺 GUI
信号确认桥「发送」→ sidecar 自动填单并截图 → 弹出**红色「真实资金委托」核对浮层**（金额醒目、标注真实盘）→
你核对截图中的代码/方向/价格/数量无误后点击「核对无误 · 提交真实委托」，sidecar 才会在客户端点「确定」。
任何护栏失败都不会触发最终确认点击。

## 7. 程序化交易报告义务（合规）

按《证券市场程序化交易管理规定（试行）》等规则，投资者进行程序化交易，通常须**自行向券商 / 证券交易所履行报告义务**。

- 武装向导与确认弹窗中已显著提示，但**报告动作需你本人完成**。
- 具体报告口径、阈值、流程以交易所和你券商的最新规定为准。
- 本软件不代为报告，也不承担未报告产生的责任。

---

## 8. 熔断与应急

- **一键急停**（工作台 / 确认桥）：封死全部新委托 → 停止自动执行 → 撤销全部条件单 → 撤销全部在途委托 → 断开券商通道。
- **解除武装**：武装向导中点击「解除武装」，真实通道立即停止接受任何真实委托，直到重新武装。
- 单日累计买入达上限后，当日不再接受真实买入（卖出不受限），次日重置。

---

## 9. 常见问题

- **提示「实盘锁定 / 请先设置单笔上限」**：单笔或单日上限为 0，先在向导设置并保存。
- **提示「标的不在白名单」**：在向导③把该 6 位代码加入白名单（武装后会要求重新武装）。
- **提示「同花顺真实通道须先完成模拟演练」**：先在模拟盘演练并勾选第④步。
- **提示「行情未就绪（缺少涨跌停价）」**：行情暂不可用，稍后重试；这是防乌龙指的保护，非故障。
- **改了限额/白名单后发现实盘被关闭**：安全参数变更会自动解除武装，重新武装即可。
- **QMT 连接失败**：确认 QMT 已极简模式登录、路径/账号正确、Python 能导入 xtquant。

## 10. 本轮交付边界（P4）

- 代码与全套安全护栏已交付并通过单测 / 构建 / 静态检查；**真实通道出厂即锁**。
- **真实资金联调**需在你开通 miniQMT 权限（或完成同花顺模拟演练）后，按本手册逐步解锁。
- 真机 QMT 下单、同花顺真实客户端控件/成交回报解析，仍以你本机实际券商客户端为准做真机校准（见 P3 真机联调手册）。
