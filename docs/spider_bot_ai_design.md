# 智能 AI 蜘蛛爬虫交易机器人 — 设计方案

---

## 一、核心理念

**不是简单的涨跌幅评分，而是用云端大模型，从多个角度智能分析。**

```
蜘蛛爬虫 = 数据采集 + AI 分析 + 自动交易
         （爬多个卡片）（大模型判断）（自动下单）
```

---

## 二、智能决策流程

### 第 1 步：多卡片数据采集
蜘蛛爬虫依次爬过各个卡片，采集数据：

| 卡片 | 采集什么数据 |
|------|-------------|
| **自选股** | 每只股票的价格、涨跌幅、成交额、量比 |
| **涨幅榜** | 前 20 名：代码、名称、涨幅、所属板块 |
| **板块行情** | 板块名称、板块涨幅、领涨股 |
| **涨停雷达** | 涨停家数、跌停家数、连板高度、炸板率 |
| **龙虎榜** | 主力资金净流入、知名席位 |

### 第 2 步：AI 智能分析
把采集到的数据打包，发给云端大模型分析：

```
发给 AI 的 Prompt：
"你是一个专业的股票交易 AI。
请根据以下数据，判断哪些股票值得买入：

【自选股】
- 贵州茅台 1258.62 +1.86% 成交额 48.0 亿
- 平安银行 11.57 +1.94% 成交额 12.1 亿
...

【涨幅榜前 10】
- 浦发银行 +3.27% 银行板块
- 招商银行 +2.85% 银行板块
...

【市场情绪】
- 涨停 59 家
- 最高 7 板
- 炸板率 5%

请输出：
1. 推荐买入的股票（代码 + 理由）
2. 推荐卖出的股票（代码 + 理由）
3. 市场整体判断（看多/看空/中性）
"
```

### 第 3 步：执行交易
根据 AI 的分析结果，自动执行：
- 买入信号 → 调用 paperStore.buy()
- 卖出信号 → 调用 paperStore.sell()

## 三、架构设计

```
┌─────────────────────────────────────────┐
│  SpiderOverlay.vue (视觉层)              │
│  - 蜘蛛在卡片上爬来爬去                    │
│  - 腿伸出去连到数据点                      │
│  - 顶部状态栏 + 日志面板                 │
└─────────────────────────────────────────┘
              ↑ 数据同步
┌─────────────────────────────────────────┐
│  useSpiderBotEngine.ts (引擎)           │
│                                          │
│  ┌─────────────────────────────────┐   │
│  │  1. 数据采集层                    │   │
│  │  - 从 DOM 读自选股列表             │   │
│  │  - 从 DOM 读涨幅榜                 │   │
│  │  - 从 DOM 读板块行情               │   │
│  │  - 从 DOM 读涨停雷达               │   │
│  └─────────────────────────────────┘   │
│                                          │
│  ┌─────────────────────────────────┐   │
│  │  2. AI 分析层                     │   │
│  │  - 把数据打包成 Prompt            │   │
│  │  - 调用云端大模型（chatSend）       │   │
│  │  - 解析 AI 返回的结果              │   │
│  └─────────────────────────────────┘   │
│                                          │
│  ┌─────────────────────────────────┐   │
│  │  3. 执行层                        │   │
│  │  - paperStore.buy()  买入         │   │
│  │  - paperStore.sell() 卖出         │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```
