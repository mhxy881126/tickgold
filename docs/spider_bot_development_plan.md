# AI 蜘蛛爬虫机器人 — 开发需求梳理

---

## 一、当前问题（为什么"乱的很"）

| 问题 | 说明 |
|------|------|
| **数据点是假的** | 股票名称、价格都是硬编码的，不是真实从卡片 DOM 里读的 |
| **位置是假的** | 数据点坐标是写死的（x=150, y=200...），不是卡片上真实元素的位置 |
| **切换卡片是假的** | 只是日志里写"切换到 XX"，右侧导航没真实选中 |
| **爬行是假的** | 蜘蛛随机移动，不是从一个真实数据点爬到下一个 |
| **腿是假的** | 腿随便连到一个点，不是连到真实的股票行上 |

**本质**：现在是一个"动画演示"，不是真实的爬虫。

---

## 二、目标：真实爬虫

### 核心理念
**蜘蛛要像真人一样，在卡片上走来走去，真实地读取每一行数据。**

### 三个真实
1. **真实位置**：数据点的坐标 = 卡片 DOM 里真实元素的位置
2. **真实数据**：文字内容 = 从 DOM 里读出来的真实股票名称/价格/涨跌幅
3. **真实操作**：切换卡片 = 右侧导航真实选中，主卡片真实切换

---

## 三、开发需求（分 4 步）

### 第 1 步：DOM 定位（找到真实元素的位置）

**目标**：从页面上找到每个卡片、每一行股票的真实坐标。

| 功能 | 说明 |
|------|------|
| **找卡片** | 通过 CSS 选择器，找到"自选股"卡片元素，获取它的 x/y/宽高 |
| **找股票行** | 在卡片内部，找到每一行股票（"贵州茅台 600519 1258.62 +1.86%"），获取它们的坐标 |
| **找数据点** | 每行里的"最新价"、"涨跌幅"、"成交额"，分别获取坐标 |

**技术**：
```js
// 伪代码
const watchCard = document.querySelector('[data-card-id="watch"]');
const rows = watchCard.querySelectorAll('.stock-row');
rows.forEach((row, i) => {
  const rect = row.getBoundingClientRect();
  // 得到这一行的真实坐标
});
```

---

### 第 2 步：真实数据读取（从 DOM 里读文字）

**目标**：蜘蛛爬到哪里，就读取那里的真实文字。

| 功能 | 说明 |
|------|------|
| **读股票名称** | 从 DOM 里读"贵州茅台"、"平安银行"等 |
| **读价格** | 读"1258.62"、"11.57"等 |
| **读涨跌幅** | 读"+1.86%"、"+1.94%"等 |
| **读成交额** | 读"48.0"、"12.1"等 |

**效果**：
- 蜘蛛爬到某一行旁边，腿尖正好指在"1258.62"上
- 标注文字就是 DOM 里真实的文字（不是硬编码的）

---

### 第 3 步：智能爬行（从一个数据点爬到下一个）

**目标**：蜘蛛不是随机移动，而是有序地从一行爬到下一行。

| 爬行顺序 | 说明 |
|---------|------|
| **自上而下** | 从第一行股票开始，一行一行往下爬 |
| **爬到下一行** | 爬完第一行，平滑移动到第二行，再到第三行... |
| **爬完切换卡片** | 自选股爬完了，平滑移动到下一个卡片（涨幅榜） |

**效果**：
```
蜘蛛爬到第 1 行（贵州茅台）
  ↓ 停 1 秒（读取数据）
平滑移动到第 2 行（平安银行）
  ↓ 停 1 秒（读取数据）
平滑移动到第 3 行（宁德时代）
  ↓ ...
爬完所有行，切换到下一个卡片
```

---

### 第 4 步：真实操作（切换卡片、下单）

**目标**：蜘蛛不只是"看"，还要能"操作"。

| 功能 | 说明 |
|------|------|
| **切换卡片** | 蜘蛛"爬"到右侧导航的"涨幅榜"上，右侧导航真实选中 |
| **点击股票** | 蜘蛛爬到某一行，"点击"一下，打开该股 K 线图 |
| **下单** | 蜘蛛"爬"到买入按钮上，"点击"一下下单 |

---

## 四、视觉效果需求

### 4.1 蜘蛛的样子
| 元素 | 要求 |
|------|------|
| **身体** | 小方块（科技感），不是大方块 |
| **腿** | 从身体伸出去，连到真实数据点（折线，有弯曲） |
| **腿尖** | 粉色小圆点，正好指在数据上 |
| **标注** | 腿旁边的文字 = 从 DOM 里读的真实文字 |

### 4.2 爬行动画
| 要求 | 说明 |
|------|------|
| **平滑移动** | 从一个点爬到下一个点，不是瞬间跳 |
| **停一下** | 爬到一个数据点，停 1 秒（表示"在读取"） |
| **腿跟着动** | 移动时，腿的弯曲程度跟着变（走路的感觉） |

---

## 五、开发优先级

| 优先级 | 功能 | 为什么重要 |
|--------|------|-----------|
| **P0** | DOM 定位（找到真实元素位置） | 没有这个，所有位置都是假的 |
| **P0** | 真实数据读取（从 DOM 读文字） | 没有这个，所有文字都是硬编码的 |
| **P1** | 智能爬行（一行一行爬） | 没有这个，蜘蛛是乱爬的 |
| **P1** | 真实切换卡片 | 没有这个，切换是假的 |
| **P2** | 真实操作（点击、下单） | 这个是进阶功能 |

---

## 六、总结

### 现在的状态
- ❌ 蜘蛛是假的（动画演示）
- ❌ 数据是假的（硬编码）
- ❌ 位置是假的（写死的坐标）

### 目标状态
- ✅ 蜘蛛是真的（在真实的 DOM 上爬）
- ✅ 数据是真的（从 DOM 里读）
- ✅ 位置是真的（getBoundingClientRect()）
- ✅ 操作是真的（真实切换卡片、真实下单）
