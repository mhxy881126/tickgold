03

授权系统设计（离线 RSA）

个人开发者无服务器：面包多收款 → 自动发货激活码 → 软件本地验签。私钥仅你持有（预生成卡密），公钥内置安装包
1
预生成卡密
本地工具批量签发年卡激活码，导入面包多库存
2
用户付款
面包多收银台（支付宝 / 微信）支付年费
3
自动发货
平台自动发放激活码，无需人工介入
4
软件内激活
用户粘贴激活码，本地 RSA 验签
5
解锁 Pro
解析到期日 → 解锁 / 到期降级免费版
激活码 = RSA-SHA256 签名的短数据（Base64 短码，约 80 字符），内含计划与到期日： TICKGOLD-PRO-2027-XXXX-XXXX-XXXX-XXXX（示例，实际为签名码） 载荷：{ plan: "pro-annual", expires_at: "2027-10-15", product: "tickgold" } 签名：RSA 私钥签名（Base64） 软件内置公钥验签 → 解析出到期日 → 解锁 Pro 至该日期
防篡改：任何字段改动都会导致验签失败；防回拨：本地记录"最近一次运行日期"，发现时间回退超过容差即拒绝 Pro 并提示校正系统时间。

06

收款与运营流程

个人收款码起步的操作细则
STEP A
开店与上架
面包多实名开店，创建"TickGold Pro 年卡"商品，定价 ¥99/年，库存导入预生成卡密
STEP B
自动发货
用户付款后平台自动发激活码；软件内粘贴激活码即离线解锁，无需你介入
STEP C
补货与续费
库存告警前用 gen_license 批量补一批年卡；到期前 7 天应用内提醒用户回店续费
STEP D
售后与退款
平台订单记录即凭证；退款纠纷走平台流程，卡密已用则不退、未用可回收再上架
面包多模式注意：① 平台对商品有合规审核，商品页与软件内不得出现"跟庄 / 胜率 / 收益承诺"等营销词（沿用合规自检清单）；② 卡密为一次性使用（软件激活后记录该码已用），丢失不补发，建议用户在面包多订单页自取；③ 平台抽成以实际结算为准，定价 ¥99 时到手约 ¥90+；④ 月收入增长后仍建议逐步转向商户直连（方案 B），费率更低、完全自控。
