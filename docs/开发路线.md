### 主要短板（2026-09-28 重新校准）



1. **后端（Rust）质量基线缺失**：Rust 仅 1 个测试模块，核心数据解析 / 口径 / 容灾无自动化回归；

2. **后端巨石文件**：`eastmoney.rs` 1212 行、`market/mod.rs` 1015 行、`lib.rs` 937 行（前端三巨石已拆，后端尚未拆）；

3. **行情抽象偏初级**：容灾为「逐源 try」，无统一 DataSource trait、无健康度指标、无请求合并；

4. **无结构化时序库**：仅 K 线整段 JSON 文件缓存，缺增量 / 去重 / 多年 / 分时 / 盘口落库，数据资产无法用于回测；

5. **行情深度不足**：无 Level-2（十档 / 逐笔 / 委托队列）；

6. **交易闭环未通**：仅模拟交易，无券商实盘接口、无本地条件单引擎；

7. **发布与生态**：无代码签名 / 公证、无插件机制、无移动端 / Linux、无云端预警。

## 二、设计原则



1. **先收口 v1.0**：把「盯盘」核心体验做到稳定、可信赖（质量、性能、签名、数据可靠），再谈高级功能；

2. **前后端质量对等**：前端有 Vitest/Playwright，后端需补 Rust 单测与集成测试，重构先有测试护栏；

3. **数据资产变现**：统一行情抽象 → SQLite 时序库 → 回测 / 量化 / 情绪指标；

4. **AI 增强而非替代**：AI 负责解读、预警、复盘，决策权始终在用户；模型与 Key 由用户选择；

5. **交易闭环**：模拟盘 → 本地条件单 → 合规券商对接，全程带风控与审计；

6. **本地优先、合规透明**：数据默认不出本机，实盘仅对接用户本人授权账户，不做投顾 / 代客理财。

## 四、阶段一・v1.0 收口

> 目标：从「功能丰富的 Beta」变成「敢用来盯实盘的 1.0」。
>
> **此阶段优先稳定与可靠，不堆无关新功能。**

### v0.72.0 盯盘体验打磨（前端）

**目标**：围绕盘中高频操作打磨键盘流与灵动岛，让盯盘更顺手；本版本尽量不扩大后端巨石。

核心功能：



* **灵动岛增强**：可配置迷你指标（价 / 涨速 / 量比 / 分时迷你图）、快捷操作、多屏停靠位置；

* **全键盘流**：自定义快捷键、命令面板动作扩展（开卡 / 切场景 / 窗口操作 / 搜索直达）；

验收标准：



* 卡片可独立成窗并跨显示器，重启后窗口位置恢复；

* 90% 常用操作可纯键盘完成，命令面板覆盖全部卡片与场景；

* 多窗口下行情轮询不倍增、帧率不下降。

### v0.73.0 后端质量与行情基线（Rust）

**目标**：为后端建立测试与抽象基线，拆分巨石，提升行情可靠性与盘口深度。**重构顺序：先补特征测试（锁定现有口径）→ 再拆文件 → 再引入 trait。**

核心功能：



* **拆 Rust 巨石**：`eastmoney.rs` 按接口域拆分（行情 / K 线 / 盘口 / 资金 / F10 / 榜单）、`mod.rs` 按数据结构与调度拆分、`lib.rs` 按 command / 窗口 / 托盘 / 更新拆分；单文件 ≤ 800 行；

* **Rust 测试基线**：各数据源 JSON → 结构解析、字段口径、涨跌停价 / 复权 / 时间换算、容灾切换顺序，目标核心模块覆盖率 ≥ 60%；CI 增加 `cargo test` 与 `cargo clippy`；

* **统一 DataSource trait**：抽象 `fetch_quotes / kline / orderbook …`，数据源健康度（成功率 / 延迟）、自动熔断与恢复、请求合并与令牌限流；

* **盘口增强**：十档展示、逐笔明细（TradeTick）、买卖盘对比、委比 / 资金博弈图；

* **Level-2 结构预留**：十档 / 逐笔 / 委托队列字段与数据源接入点，支持用户自带数据源或 API Key。

验收标准：



* 单文件 ≤ 800 行，`cargo test` 核心模块覆盖率 ≥ 60%，`cargo clippy` 无 warning；

* 任一数据源故障数秒内无感切换，熔断 / 恢复行为可观测（健康面板）；

* 盘口信息密度与可读性达到主流终端水平；L2 字段可承载但不承诺免费来源。

### v0.74.0 本地时序库

**目标**：把行情流沉淀为结构化本地时序数据，断线不丢、离线可看，为 v1.1+ 量化铺路。

核心功能：



* **SQLite 时序表**：K 线 / 分时 / 盘口 / 逐笔快照，统一主键（code + period + timestamp），增量 upsert、去重、完整性校验；

* **同步策略**：盘前自动补历史、盘中增量写入、断线续传、缺口检测与回补；

* **缓存收敛**：现有 K 线 JSON 文件缓存迁移 / 并入时序库，保留只读兜底；

* **数据管理**：按品种 / 时段配置保留周期与存储上限，支持导出与清理。

验收标准：



* 本地 K 线 / 分时可离线浏览，断网重启数据不丢失、无重复；

* 缺口可自动检测并回补，存储占用可控；

* 数据口径文档化、字段可追溯，写入不影响盯盘帧率。

### v1.0.0 正式版・LTS ★里程碑

**目标**：发布稳定、可信赖、可长期使用的 1.0，敢用于实盘盯盘。

核心功能：



* Windows /macOS 代码签名与公证（notarization），消除安全警告；

* 全量回归（前端 + Rust + E2E + 视觉 / 性能）达标，发布前冻结与灰度；

* 完整用户手册、快捷键、视频教程、FAQ 定稿；

* 安装 / 更新 / 卸载 / 数据备份恢复终验。

验收标准：



* 全平台无未签名安全拦截，更新链路可靠；

* 崩溃率 < 0.5%，核心场景零 P0 / P1 缺陷；

* 文档与实际版本一致，形成 v1.0 LTS 维护分支。

## 五、阶段二・数据与量化

> 目标：从「看盘工具」升级为「研究 / 复盘 / 验证体系」，让本地数据资产产生价值。

### v1.1.0 历史复盘增强



* 完整历史行情库（多年 K 线 / 分时 / 盘口，在 v0.74 时序库上扩展深度）；

* 历史盘面重建：当日情绪、涨停池、板块、龙虎榜一键回放；

* 复盘标注、笔记、截图、关键事件标记；整合历史分时回放与多日叠加。

* **验收**：近 3–5 年任意交易日可离线重建盘面；复盘内容可检索、可导出、可关联个股。

### v1.2.0 条件选股与公式



* 选股器增强：技术 / 财务 / 资金 / 形态 / 情绪多维组合，可保存、定时运行；

* 自定义指标 / 公式引擎（表达式或类通达信语法，安全沙箱执行）；

* 选股结果实时跟踪、回测、转预警 / 股票池；动态策略股票池自动进出。

* **验收**：常用条件无需写公式即可组合；公式沙箱安全、结果可复算；策略可定时运行推送。

### v1.3.0 本地回测引擎



* K 线 / 分时 / Tick 多频度回测，A 股撮合规则（涨跌停、T+1、停牌、流动性约束）；

* 手续费、印花税、滑点、成交比例等真实成本建模；

* 内置策略模板：打板、低吸、趋势、均线、网格；

* 绩效报告：收益 / 基准、最大回撤、夏普、胜率、盈亏比、逐笔明细。

* **验收**：无未来函数；结果可复现、口径清晰；报告可导出、策略一键转模拟盘。

### v1.4.0 模拟盘与条件单



* 模拟盘实时撮合、多账户、与回测策略联动；

* 本地条件单：价格 / 时间 / 指标触发，止盈止损、追踪止损、网格；

* 信号执行模式：人工确认 / 自动执行（模拟盘）；仓位管理与回撤熔断。

* **验收**：条件单触发准确、可撤可改、日志完整；撮合贴近真实；风控可强制生效。

### v1.5.0 情绪周期量化



* 情绪周期识别：冰点 / 回暖 / 高潮 / 退潮（涨停、炸板、连板、溢价、赚钱效应）；

* 情绪指标：封板率、晋级率、溢价率、连板高度、亏钱效应；

* 周期 × 策略适配：不同阶段推荐打法与仓位；历史情绪库与策略表现对照。

* **验收**：周期判定与人工大体一致并可解释；指标实时、历史可回溯；给出可执行仓位 / 打法建议（仅辅助）。

## 六、阶段三・AI 智能

> 目标：AI 贯穿选股 / 盯盘 / 复盘，做「少而懂你」的智能助手，决策权在人。

### v2.0.0 AI 盯盘助手



* 本地数据 / 能力封装为标准工具接口（MCP），可接本地 Ollama 或用户自带云端 Key；

* 自然语言选股与问答，结果可转策略 / 预警；

* 异动实时解读：拉升 / 封板 / 炸板 / 大单的原因、历史相似、可能意图；

* 智能盯盘：全市场自动扫描异动，按用户偏好推送；

* AI 盘口解读与自动复盘；自动画线、形态识别、多周期支撑阻力。

* **验收**：模型与 Key 用户可选、本地模式数据不外发；结论附来源、可核验、可跳转证据；覆盖选股 / 盯盘 / 复盘主流程。

## 七、阶段四・生态与平台

> 目标：打通交易最后一公里，开放插件生态，扩展平台与品种，远期走向平台化。

### v2.1.0 交易对接（合规）



* 对接 QMT / Ptrade 或券商官方 API（用户自行开通、自有账户）；

* 实盘条件单 / 信号执行，强制风控与二次确认；

* 本地凭据加密、操作审计、完整风险揭示。

* **验收**：仅对接本人授权账户、凭据加密；实盘有风控熔断、可一键撤单；明确合规边界。

### v2.2.0 插件生态



* 插件机制：卡片、指标、数据源、策略、主题插件；

* 插件市场、签名校验、安全沙箱；主题 / 布局 / 策略一键分享导入。

* **验收**：插件 API 稳定、文档齐全、权限最小化；社区插件可安全安装、审计、卸载。

### v2.3.0 多平台与多品种



* Linux 版本；移动端伴侣 App / Web 端；

* 云同步：自选、布局、预警、设置多端一致；

* 港股通 / 美股 / ETF / 可转债 / 指数 / 期货扩展；云端预警关机也能推送。

* **验收**：三端数据一致、冲突可处理；新品种口径完整；云端预警到达率与时延达标。

### v3.0.0 平台化（远景）



* 云端策略运行与多设备协同；社区观点 / 策略 / 复盘分享；团队 / 机构版共享股票池、协作与权限。

* **验收**：云端运行稳定、数据安全合规；社区内容有治理，团队权限清晰。

## 九、关键依赖链



* **v1.0 收口**：前端基线（✅）→ 预警引擎（✅）→ 盯盘体验（v0.72）→ **后端质量 + 行情基线（v0.73）→ 时序库（v0.74）** → v1.0 签名发布；

* **数据量化**：时序库（v0.74）→ 多年历史（v1.1）→ 选股 / 公式（v1.2）→ 回测（v1.3）→ 模拟盘 / 条件单（v1.4）→ 情绪周期（v1.5）；

## 十、优先级与节奏建议



* **v1.0 收口是最高优先级**：盯盘体验 + 后端可靠 + 签名，再谈高级功能；

* **后端债务优先于新功能**：v0.73 /v0.74 是阶段二全部工作的地基，重构必须测试先行；

* **AI 不必干等**：数据接口就绪后可并行探索，但结论需可核验、决策权在用户；

* 优先级矩阵：


  * 高价值 / 低成本（立即做）：多窗口、键盘流、灵动岛、L2 预留；

  * 高价值 / 高成本（重点投入）：后端测试与抽象、时序库、回测、AI、券商对接；

  * 低价值 / 高成本（暂缓）：自研移动端、机构版。
