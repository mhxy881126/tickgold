# TickGold 开发路线与版本规划

> 为「交易者盯盘」而生的跨平台 A 股桌面终端。本文件记录 TickGold 从当前版本走向 v1.0、量化、AI 与生态平台的**完整开发路线、功能需求迭代与版本规划**。
>
> - 技术栈：Tauri 2（Rust）+ Vue 3 + TypeScript + Pinia + KLineChart / ECharts + SQLite
> - 当前版本：**v0.71.0**（v0.70.0 数据层加固经评估后暂缓，直接进入可视化预警引擎）
> - 仓库：<https://github.com/mhxy881126/tickgold>
> - 最后更新：随版本迭代同步维护

---

## 一、现状盘点

### 已具备的能力

| 维度 | 现状 |
| --- | --- |
| 功能卡片 | **33 张**，归并为 6 大域：大盘总览 / 盯盘模式 / 情绪异动 / 板块题材 / 个股行情 / 交易工具 |
| 场景与模式 | 5 套场景模板（盘中盯盘 / 开盘竞价 / 盘后复盘 / 条件选股 / 极简看盘）+ 5 套全屏盯盘模式 |
| 行情数据 | 9 个数据源模块（东方财富 / 新浪 / 腾讯 / 巨潮等），多源故障转移、退避重试、限流 |
| 本地能力 | SQLite 时序快照库、布局 / 自选 / 预警本地持久化、灵动岛悬浮窗 |
| 交易相关 | 模拟交易、盯盘日记、龙虎榜游资席位与胜率追踪、条件选股 |
| 外观体验 | 9 套配色主题、卡片自由布局、单卡聚焦、右键菜单、撤销重做 |
| 工程化 | GitHub Actions 发布流水线、安装前 DB 备份、更新签名校验 |

### 主要短板

1. **质量保障缺失**：零自动化测试、无代码签名（Windows / macOS），回归依赖人工；
2. **代码结构**：3 个超大文件（`App.vue`、`StockChart.vue`、`useWorkbench.ts`），维护与协作成本高；
3. **数据资产闲置**：本地快照数据未用于回测、量化与情绪指标；
4. **行情深度不足**：无 Level-2 深度数据（十档 / 逐笔 / 委托队列）；
5. **交易闭环未通**：仅模拟交易，无券商实盘接口、无本地条件单引擎；
6. **生态与平台**：无插件机制、无移动端 / Linux、无云端预警。

## 二、设计原则

1. **先收口 v1.0**：把「盯盘」核心体验做到稳定、可信赖（质量、性能、签名、测试），再谈高级功能；
2. **数据资产变现**：本地 SQLite 快照 → 历史库 → 回测 / 量化 / 情绪指标；
3. **AI 增强而非替代**：AI 负责解读、预警、复盘，决策权始终在用户；模型与 Key 由用户选择；
4. **交易闭环**：模拟盘 → 本地条件单 → 合规券商对接，全程带风控与审计；
5. **本地优先、合规透明**：数据默认不出本机，实盘仅对接用户本人授权账户，不做投顾 / 代客理财。

## 四、阶段一 · v1.0 收口

> 目标：从「功能丰富的 Beta」变成「敢用来盯实盘的 1.0」。**此阶段优先稳定，不堆新功能。**

### v0.69.0 质量与性能基线

**目标**：建立工程质量与性能基线，拆分巨石文件，让后续迭代不再「牵一发动全身」。

核心功能：

- 拆分 `App.vue` / `StockChart.vue` / `useWorkbench.ts` 三个超大文件，按职责抽 composable 与子组件；
- 引入 Vitest 单元测试，覆盖数据解析、指标计算、布局装箱、状态管理；
- 关键链路 E2E（CDP 驱动：开卡 / 聚焦 / 场景切换 / 数据加载）；
- 性能优化：长列表虚拟滚动、卡片按需挂载、图表实例复用与销毁、内存泄漏排查；
- 建立视觉回归基线，防止 K线布局类回归再次出现。

验收标准：

- 单文件 ≤ 800 行，核心模块单测覆盖率 ≥ 60%；
- 全量卡片同屏帧率 ≥ 50fps，连续运行 4h 内存无明显增长；
- CI 中测试、构建、视觉回归全部通过。

### v0.70.0 数据层加固

**目标**：统一行情抽象、夯实本地时序库，为回测 / 情绪 / AI 提供干净可靠的数据底座。

核心功能：

- 行情统一 adapter 层 + 数据源健康监测、自动故障转移、请求合并与限流；
- SQLite 时序库：K线 / 分时 / 盘口 / 逐笔快照，增量同步、去重、完整性校验；
- 盘前自动补历史、断线续传、缺口检测与回补；
- Level-2 数据结构预留（十档 / 逐笔 / 委托队列），支持用户自带数据源或 API Key。

验收标准：

- 任一数据源故障可在数秒内无感切换；
- 本地 K线 / 分时数据可离线浏览，断网重启数据不丢失；
- 数据口径文档化、字段可追溯。

### v0.71.0 可视化预警引擎

**目标**：从「固定预警」升级为用户可自由组合的条件预警，少而准地推送真正关心的信号。

核心功能：

- 条件构建器：价格 / 涨跌幅 / 量比 / 换手率 / 技术指标 / 盘口 / 竞价 / 时间，多条件 AND / OR 组合；
- 触发动作：系统通知、声音、弹窗、联动卡片、自动打开 K线 / 盘口；
- 去重、节流、静默时段、仅一次 / 每日 / 持续频率控制；
- 预警模板库：突破前高、回踩均线、封板 / 炸板、竞价抢筹、放量异动。

验收标准：

- 不写代码即可配置任意组合预警，触发延迟 ≤ 1 个刷新周期；
- 预警不重复轰炸，模板覆盖主流短线场景；
- 预警历史可回看，可一键转条件单 / 选股。

## 五、阶段二 · 数据与量化

> 目标：从「看盘工具」升级为「研究 / 复盘 / 验证体系」，让本地数据资产产生价值。

### v1.1.0 历史复盘增强

**目标**：任意历史交易日盘面可重建，形成个人复盘资产。

核心功能：

- 完整历史行情库（多年 K线 / 分时 / 盘口）；
- 历史盘面重建：当日情绪、涨停池、板块、龙虎榜一键回放；
- 复盘标注、笔记、截图、关键事件标记；
- 整合历史分时回放与多日叠加能力。

验收标准：

- 近 3–5 年任意交易日可离线重建盘面；
- 复盘内容可检索、可导出、可关联个股。

### v1.2.0 条件选股与公式

**目标**：多维可视化选股 + 安全的自定义指标 / 公式，快速验证策略想法。

核心功能：

- 选股器增强：技术 / 财务 / 资金 / 形态 / 情绪多维组合，可保存、定时运行；
- 自定义指标 / 公式引擎（表达式或类通达信语法，安全沙箱执行）；
- 选股结果实时跟踪、回测、转预警 / 股票池；
- 动态策略股票池，按规则自动进出。

验收标准：

- 常用财务 / 技术 / 资金条件无需写公式即可组合；
- 自定义公式在沙箱内安全运行、结果可复算；
- 选股策略可定时运行并推送结果。

### v1.3.0 本地回测引擎

**目标**：基于本地数据严谨回测交易想法，用数据验证策略有效性。

核心功能：

- K线 / 分时 / Tick 多频度回测，A股撮合规则（涨跌停、T+1、停牌、流动性约束）；
- 手续费、印花税、滑点、成交比例等真实成本建模；
- 内置策略模板：打板、低吸、趋势、均线、网格；
- 绩效报告：收益 / 基准、最大回撤、夏普、胜率、盈亏比、逐笔交易明细。

验收标准：

- 回测无未来函数，信号仅用当时可得数据；
- 结果可复现，成本口径清晰可调；
- 报告可导出，策略可一键转模拟盘。

### v1.4.0 模拟盘与条件单

**目标**：策略信号可在模拟盘自动执行，本地条件单覆盖止盈止损 / 网格。

核心功能：

- 模拟盘实时撮合、多账户、与回测策略联动；
- 本地条件单：价格 / 时间 / 指标触发，止盈止损、追踪止损、网格；
- 信号执行模式：人工确认 / 自动执行（模拟盘）；
- 仓位管理与风控：仓位建议、风险度、回撤熔断。

验收标准：

- 条件单触发准确、可撤可改、有完整执行日志；
- 模拟盘撮合贴近真实规则；
- 风控阈值可配置并可强制生效。

### v1.5.0 情绪周期量化

**目标**：自动识别情绪周期并匹配打法 / 仓位，把「看情绪」变成可量化指标。

核心功能：

- 情绪周期识别：冰点 / 回暖 / 高潮 / 退潮（基于涨停、炸板、连板、溢价、赚钱效应）；
- 情绪指标：封板率、晋级率、溢价率、连板高度、亏钱效应；
- 周期 × 策略适配：不同阶段推荐打法与仓位；
- 历史情绪库与策略表现对照。

验收标准：

- 周期判定与人工判断大体一致并可解释；
- 情绪指标实时更新、历史可回溯；
- 给出可执行的仓位 / 打法建议（仅辅助决策）。

## 六、阶段三 · AI 智能

> 目标：AI 贯穿选股 / 盯盘 / 复盘，做「少而懂你」的智能助手，决策权在人。

### v2.0.0 AI 盯盘助手

**目标**：以标准工具接口接入用户自选模型，让 AI 增强而非替代交易者。

核心功能：

- 本地数据 / 能力封装为标准工具接口（MCP），可接本地 Ollama 或用户自带云端 Key；
- 自然语言选股与问答，结果可转策略 / 预警；
- 异动实时解读：拉升 / 封板 / 炸板 / 大单的原因、历史相似、可能意图；
- 智能盯盘：全市场自动扫描异动，按用户偏好推送，无需逐条手设条件；
- AI 盘口解读与自动复盘（情绪判断、明日计划）；
- 自动画线、形态识别、多周期支撑阻力。

验收标准：

- 模型与 Key 由用户选择，本地模式数据不外发；
- AI 结论附数据来源、可核验、可一键跳转证据；
- 覆盖选股 / 盯盘 / 复盘主流程，明显减少手工操作。

## 七、阶段四 · 生态与平台

> 目标：打通交易最后一公里，开放插件生态，扩展平台与品种，远期走向平台化。

### v2.1.0 交易对接（合规）

**目标**：在合规与用户自有账户前提下，打通信号到实盘的最后一公里。

核心功能：

- 对接 QMT / Ptrade 或券商官方 API（用户自行开通、自有账户）；
- 实盘条件单 / 策略信号执行，强制风控与二次确认；
- 本地凭据加密、操作审计、完整风险揭示。

验收标准：

- 仅对接用户本人授权账户，凭据加密存储；
- 实盘操作有风控熔断、可追溯、可紧急一键撤单；

## 九、优先级与节奏建议

- **v1.0 收口是最高优先级**：先把稳定性、性能、签名、测试做扎实，再谈高级功能；
- **数据层是共同前置**：回测、情绪、AI 都依赖干净可靠的数据，应尽早投入；
- **AI 不必干等**：数据接口就绪后即可并行探索，但所有结论需可核验、决策权在用户；
- 优先级矩阵：
  - 高价值 / 低成本（立即做）：预警引擎、可视化选股、盘口增强、质量基线、多窗口；
  - 高价值 / 高成本（重点投入）：回测引擎、情绪周期、AI 盯盘、券商对接；
  - 低价值 / 高成本（暂缓）：自研移动端、机构版。
