### 主要短板



1. **AI 只差前端一层皮**：后端命令、向量检索、只读工具 Agent、前端 api/useAiChat 全部就绪，但**没有任何 AI 界面**—— 无聊天面板、设置里无模型配置入口、无知识库管理页、Mega 菜单无入口，用户尚无法触达；

2. **知识入库范围待扩**：md/txt 手动导入与日度自动入库已通，但公告 / 互动易 / 快讯 / 盯盘日记的自动 chunk + embedding 全量接入仍在进行，引用溯源（FactRef）需在 UI 上落地为可点击跳转；

3. **后端质量基线仍薄**：Rust 测试集中在少数模块，`cargo test/clippy` 未进 CI，lib.rs 等巨石仍在；

4. **行情深度不足**：免费 5 档，无 Level-2（十档 / 逐笔委托队列）；

5. **交易闭环未通**：仅前端模拟盘，无本地条件单引擎、无券商实盘接口；

6. **发布与生态**：无 Authenticode / 公证、无插件机制、无移动端 / Linux / 云同步。

## 二、设计原则（2026-10-01 重新校准）



1. **双脑分工**：慢脑（System 2，生成式 LLM）负责采集后的研究、复盘、计划与工具调用；快脑（System 1，Laya 非自回归分类器，约 33ms）负责盘中实时决策；二者共用同一套特征与本地数据；

2. **决策权分层**：模拟账户可全自动执行；实盘账户**只出信号、人工确认**，强制风控与审计。本项目不做投顾、不代客理财；

3. **数据 → 知识 → 决策 → 回灌**：时序数据沉淀为题材 / 知识库，知识库喂养双脑，决策落日志，成交结果打标回灌形成进化闭环；

4. **本地优先、合规透明**：默认本地 Ollama / 本地库，数据不出本机；云端模型与 Key 由用户自选（keyring 加密存储）；任何 AI 结论必须附来源、可核验、可跳转证据；

5. **策略外置版本化**：龙头 / 1 进 2 / 抄底等打法为外部、带版本号的 strategy\_profile，与模型版本分别管理，效果可对照可回滚；

6. **盯盘基本盘不回归**：每次迭代必须通过 tsc + 452 单测 + E2E（含性能基线）才允许发版。

## 五、v2.0.0 AI 复盘 + 作战计划

> 目标：盘后从「人翻数据」变成「慢脑产出结构化复盘与次日计划」，人做审批与修正。



* **决策特征包**：整合题材 / 成分角色 / 催化剂 / 时序快照 / 龙虎榜 / 持仓，产出约 30–40 个特征的统一 decision-pack（快慢脑共用）；

* **新增表**：company\_note、strategy\_profile、ai\_review、plan、plan\_instruction、kb\_document（以迁移为准）；

* **盘后自动复盘**：收盘采集完成后触发慢脑，生成当日市场 / 题材 / 个股三层复盘，写入 ai\_review，结论逐条挂证据；

* **策略 profile**：龙头 / 1 进 2 / 抄底三套外置版本化配置（入场上的阈值、仓位、止盈止损规则），界面可查看与克隆；

* **作战计划**：慢脑依据复盘 + profile 生成次日 plan 与 plan\_instruction（观察 / 候选 / 触发条件），用户可编辑批准，计划与自选、持仓、预警联动。

**验收**：近一个交易日复盘可离线重跑；计划字段结构化、可转预警；profile 改动有版本记录可回滚；所有 AI 文案可追溯到本地数据证据；全套测试与 E2E 绿。

## 六、v2.1.0 快脑盯盘决策（闭环首通）★里程碑 ✅ 已交付

> 目标：快脑盘中实时输出决策，模拟盘完成「信号 → 风控 → 执行 → 记录」全自动首通；实盘仅信号 + 人工确认。
> **实际落地口径**
>
> ：设计中的 Laya 为基于 ModernBERT 的非自回归决策模型，以本地 HTTP sidecar（pip 部署、需训练权重）存在，无法在 Tauri 内直接打包，冷启动也无标注样本。故本版交付
>
> **双脑同接口**
>
> ：内置 
>
> **RuleBrain（规则 / 因子加权 → sigmoid → 四类概率，默认、零依赖、可解释）**
>
>  \+ 
>
> **LayaClient（HTTP sidecar 客户端，短超时健康检查，失败自动降级 RuleBrain）**
>
> 。



* **双脑分类器**：买入 12 因子 / 卖出 6 因子加权，输出 BUY / NO\_BUY / HOLD / SELL 及各类概率；模型版本经 model\_version 登记（规则脑版本 rule-tickgold-v1）；

* **决策执行**：decision\_log 记录每次决策的特征快照、概率、理由；阈值 —— 概率 ≥0.75 执行（模拟盘）、0.55–0.75 列入观察、<0.55 丢弃；

* **账户分策略**：模拟账户按 plan\_instruction 全自动；实盘账户只推送信号到灵动岛 / 对话面板，人工确认后方可流转（v2.3 前无真实下单通道）；

* **风控闸门**：仓位上限、单票上限、回撤熔断、交易时段与涨跌停约束，在执行层强制生效，任何模型不得绕过；

* **前端**：快脑决策条（当前标的信号 + 概率 + 触发特征）、模型运行状态（延迟 / 版本）、决策日志卡片。

**验收**：盘中决策端到端延迟满足盯盘时效；特征与概率可解释、可回放；模拟盘在一个完整交易周内自动闭环、风控零绕过；断网 / 模型加载失败安全降级为不出信号；全套测试 + E2E + 长时间浸泡达标。

## 七、v2.2.0 回灌进化 ✅ 已交付

> 目标：让决策结果变成训练 / 评估素材，双脑开始自我进化（人保留最终裁定）。



* **交易打标**：trade\_label 对历史决策按后续 N 日收益、是否触及止盈止损自动打标；

* **效果回灌**：按 model\_version × strategy\_profile 输出胜率、盈亏比、期望收益、误判类型分布；

* **慢脑周期复盘**：周 / 月维度总结打法有效区间，提出 profile 参数调优建议，**须人工批准**才生效；

* **数据治理**：特征 / 决策 / 标签链路一致性校验与过期数据清理。

**验收**：任一历史决策可追溯「特征 → 概率 → 执行 → 标签 → 收益」全链路；版本效果对照报表可导出；参数变更全程留痕可回滚。

**落地实现（v2.2.0）**：



* 迁移 v44 新增 `trade_label`（决策唯一，含 1/2/3/5 日收益、最大涨 / 跌、止盈止损标记、verdict、误判类型、三索引）；

* 打标口径：决策基准价取特征快照 `price`（缺省回退决策日收盘），对后续日 K 计算收益与止盈（默认 +10%）/ 止损（默认 -7%）触及；BUY 与 SELL 好坏方向相反，误买标 `false_positive`、卖飞标 `sell_too_early`；含 `watch` 观察单、排除 `drop`；

* 效果汇总：按 model\_version × strategy 输出样本、胜率、均盈 / 均亏、盈亏比、期望收益、平均收益、止盈止损与误判计数；

* 数据治理：校验缺标签 / 零周期 / 孤儿标签 / 未登记模型，可清理孤儿与过期（默认 180 天）决策与标签；

* 前端「交易工具 → 进化回灌」卡片：参数可调（止损 / 止盈 / 周期 / 含观察）、效果对照与标签明细双视图、verdict 过滤；**调参仅产出统计依据，参数变更须人工批准，不自动改写 profile**。
