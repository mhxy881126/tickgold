方案对比

A · 时间流版
时间戳+板块名+涨跌幅+领涨股/资金
优点：像看新闻流，最新异动一眼看到
缺点：没有排名感
B · 卡片版
2列卡片，每个板块一个独立卡片
优点：信息密度高，一屏看多个板块
缺点：滚动多了找不到重点
C · 排行榜版
带排名数字，可切换涨幅/资金/跳水榜
优点：一眼看到谁最强，排名清晰
缺点：缺少时间维度
