方案对比

A · 时间流版
每一行=一条异动，时间+类型标签+股票+数据
优点：信息最全，一眼看到股票名和涨跌幅
缺点：密度高，快速扫过需要适应
B · 统计面板版
顶部4格统计今日异动总数，下方最新异动列表
优点：先看整体情绪，再看具体个股
缺点：统计数字多了可能占空间
C · 消息流版
聊天气泡式，左边框颜色=异动类型
优点：视觉轻松，像看消息通知
缺点：股票名和涨跌幅不够突出
