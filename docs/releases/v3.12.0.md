# v3.12.0 — 作战台 2.0 与「计划即执行」闭环

> 发布日期：2026-10-20　|　基线：v3.11.1　|　类型：功能版本

## 亮点

### 作战台 2.0（P0）
- 非线性时间轴：6 时段 + 开盘三子段（首波/承接/分歧），开盘占 46% 视觉宽度，1s 倒计时。
- 阶段面板「现在该做」：盘前/竞价/开盘/盘中/尾盘/盘后各有清单与计划股实时涨幅。
- 下单条：代码/价格 chips/数量/仓位档/买卖/一次确认；模拟·实盘徽标；实盘未启用前置拦截。
- 右上角「旧版六步 / 新版作战台」一键回退；旧 Cockpit 保留。

### 计划即执行（P1）
- 作战卡指令 → 条件单物化：计划日当天、仅 confirmed、open/alerted 指令；幂等 + 唯一约束；跨午夜定时物化。
- 独立条件单触发循环：交易时段 5s，旧预警引擎不再重复评估。
- 指令状态机：仅观察/待触发/已触发/已下单/已成交/已取消/已过期；手动撤销=放弃指令、急停=撤单+暂停物化、重开=重新物化。
- 触发条件行内编辑；触发后「确认并提交已有信号票」走 `submit_with_sig` 九道闸门；模拟盘自动可按条关闭。
- 盘后 15:05 自动生成次日作战卡；8:45 应用内横幅提醒；确认后推进盯盘并出现「开始盯盘」。
- 作战台命中率：近 20 日触发/执行/胜率（有价成交口径）。

### 实盘闭环与提速（P2）
- 对账状态常驻 chip（正常/账实不符/未对账）；live 重连后全量持仓帧自动 intraday 对账，连接代际丢弃迟到结果。
- 下单耗时埋点：最近/中位耗时 + 点击次数。
- 常见下单错误中文化（重复提交/无记录/库忙/超时/未连接）。
- B/S/C/W/D 全局快捷键；信号桥优先级排序 + 高/中/低徽标；高优信号灵动岛红色脉冲与限流展开。
- 菜单重组为 4 场景组（行情·选股 / 盯盘·复盘 / 交易·执行 / 工具·系统），旧分组配置自动迁移。

### 智能（P3）
- Copilot：自然语言 → 条件单草稿（价格/涨跌幅/方向/数量），预览确认后只创建本地条件单。
- 盘口五档点击预填（卖档→买、买档→卖）、分时点击预填、全局选中股联动。
- 指令打标（逻辑/情绪/跟风）→ 按代码历史成交率计算次日权重（0.8–1.2），参与计划评分。

## 数据与兼容
- 迁移新增：v61（指令物化列）、v62（计划条件单唯一索引）、v63（指令 tag）。
- `dock_groups_v1` 升级为 v2：旧 6 组内置配置自动迁移为 4 组，自定义组保留。
- 实盘仍默认关闭、下单仍需人工确认；所有提交仍经 `submit_with_sig`。
