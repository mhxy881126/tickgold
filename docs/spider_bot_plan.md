# AI 爬虫机器人 - 完整功能需求与实现方案

## 一、需求定义

### 核心目标
启动"AI 爬虫机器人"后，一个科技感蜘蛛效果**直接覆盖在整个 TickGold 应用上**，它像人一样：
1. 自动切换各个菜单卡片
2. 抓取每个窗口的信息（蜘蛛腿伸到各个信息点上）
3. 标注抓取到的信息
4. 筛选股票（自动判断哪些符合条件）
5. 自动执行交易买卖

### 不是什么
- ❌ 不是一个卡片里显示日志/进度
- ❌ 不是外部 Python 脚本
- ❌ 不是只在卡片内部显示蜘蛛动画

### 是什么
- ✅ 全局覆盖层（Overlay），蜘蛛显示在整个应用最上层
- ✅ 自动操作应用（切换卡片、点击按钮）
- ✅ 实时抓取数据（从各个 store 读）
- ✅ 视觉反馈（蜘蛛腿 + 标注 + 高亮框）

## 三、模块拆分

### 1. SpiderOverlay.vue（全局覆盖层组件）

**职责**：
- 全屏覆盖在应用最上层（position: fixed, z-index: 9999）
- SVG 画蜘蛛（蓝色方块身体 + 青色弯曲腿 + 粉色光点）
- 半透明背景（让用户能看到下面的应用）
- 顶部状态栏（显示当前正在扫描什么）

**Props**：
- `visible: boolean` — 是否显示
- `spiderX, spiderY: number` — 蜘蛛身体位置
- `targetPoints: Array<{x, y, label, type}>` — 腿尖连接的目标点
- `currentPoint: {x, y}` — 当前正在扫描的点（高亮）

### 2. useSpiderBot.ts（爬虫引擎 composable）

**状态**：
- `running: boolean` — 是否在运行
- `currentStep: number` — 当前第几步
- `currentCard: string` — 当前正在扫描的卡片
- `targetPoints: Array` — 当前帧的目标点（蜘蛛腿要连到哪里）

**扫描流程**：
```
步骤 1: 自选股卡片
  - 切换到 watch 卡片
  - 读取自选股列表（6 只股票）
  - 蜘蛛腿连到每只股票的位置
  - 逐只扫描，评估是否符合买入条件

步骤 2: K 线图卡片
  - 切换到 chart 卡片（当前选中的股票）
  - 读取 K 线数据
  - 蜘蛛腿连到关键指标（价格、涨跌幅、MA5/MA10）

步骤 3: 涨停雷达卡片
  - 切换到 radar 卡片
  - 读取涨停股票列表
  - 蜘蛛腿连到涨停股

步骤 4: 板块卡片
  - 切换到 sector 卡片
  - 读取板块涨幅榜
  - 蜘蛛腿连到领涨板块

步骤 5: 交易卡片
  - 切换到 trade 卡片
  - 如果有买入信号，自动执行交易
  - 蜘蛛腿连到买入按钮

循环...
```

### 3. 触发入口

在灵动岛或者工具栏上加一个"🕷 爬虫机器人"按钮，点击启动/停止。

## 四、视觉效果规范

### 蜘蛛身体
- 位置：屏幕中央偏上（可以移动）
- 形状：蓝色方块 + 三层发光光晕
- 大小：约 40x40 px

### 蜘蛛腿
- 颜色：青色（#00dcff）
- 形状：多关节弯曲折线（3-4 个弯）
- 粗细：2px（当前扫描的腿 3px）
- 数量：根据目标点数量动态变化（10-20 条）

### 腿尖光点
- 颜色：粉色（#ff5096）
- 形状：圆点 + 多层光晕
- 大小：4px（当前扫描的 8px）

### 高亮框
- 当前扫描的股票行/卡片：红色半透明高亮框
- 符合买入条件的：绿色高亮框
- 符合卖出条件的：红色高亮框

## 五、实现步骤

### Phase 1: 基础框架（今天）
1. 创建 `SpiderOverlay.vue` 全局覆盖层组件
2. 创建 `useSpiderBot.ts` 爬虫引擎
3. 加一个启动/停止按钮
4. 实现基础的蜘蛛效果显示

### Phase 2: 自动切换卡片（下一步）
1. 接入 dock store，实现自动切换卡片
2. 每个卡片切换后，计算对应的目标点位置
3. 蜘蛛腿实时连到这些点

### Phase 3: 数据抓取与筛选
1. 从各个 store 读取数据
2. 实现筛选逻辑（涨跌幅/成交额/量比）
3. 符合条件的标记为买入/卖出信号

### Phase 4: 自动交易
1. 接入交易 API
2. 自动执行买入/卖出
3. 记录交易日志
