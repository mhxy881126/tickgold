# AI 蜘蛛爬虫交易机器人 — 产品需求文档（PRD）

> 版本：v1.0
> 定位：TickGold 内置 AI 自主盯盘交易助手

---

## 一、产品定位

### 1.1 一句话定义
**一个像真人操盘手一样，自主在 TickGold 各个卡片之间游走、读取数据、分析判断、自动下单的 AI 爬虫机器人。**

### 1.2 不是什么
- ❌ 不是一个"蜘蛛动画特效"
- ❌ 不是一个"策略回测工具"
- ❌ 不是一个"选股器面板"
- ❌ 不是外部脚本

### 1.3 是什么
- ✅ 是一个**数字分身操盘手**——你开着它去吃饭/开会，它替你盯盘
- ✅ 是一个**可视化的爬虫**——你能看到它在屏幕上"爬"过每个卡片
- ✅ 是一个**闭环交易系统**——发现机会 → 分析 → 下单 → 跟踪 → 止盈止损

---

## 二、核心用户场景

### 场景 1：盘中忙不过来（最典型）
> 小王是上班族，只有 9:25-9:30 能看一眼盘。9:30 开盘后就要开会。
>
> **他要的**：打开 AI 爬虫机器人，让它替我盯盘。涨停板开了、自选股异动了、板块轮动了，它自己去看、自己判断、自己提醒我或者直接帮我买。

### 场景 2：多窗口盯不过来
> 小李是短线选手，同时盯 6 个窗口：自选股、涨停雷达、板块、涨幅榜、龙虎榜、交易面板。
>
> **他要的**：我看不过来，让 AI 替我爬。它从自选股爬到涨停雷达，从涨停雷达爬到板块，从板块爬到交易面板，发现好机会就告诉我，我点头它就买。

### 场景 3：睡觉也能赚钱
> 老张是中长线，不想盯盘但也不想错过机会。
>
> **他要的**：开着机器人，晚上睡觉。它自己判断趋势、自己止盈止损，第二天早上我看结果就行。

## 三、功能需求定义

### 3.1 核心功能模块总览

| 模块 | 功能 | 优先级 |
|------|------|--------|
| **M1. 爬虫漫游** | 自动在各个卡片之间切换、游走 | P0 |
| **M2. 数据采集** | 从每个卡片读取实时数据 | P0 |
| **M3. 分析决策** | 基于读取的数据，判断买卖信号 | P0 |
| **M4. 视觉反馈** | 蜘蛛特效 + 标注 + 高亮，让用户看到它在干嘛 | P0 |
| **M5. 自动交易** | 触发信号后自动下单 | P1 |
| **M6. 风控管理** | 仓位控制、止损止盈、急停 | P0 |
| **M7. 日志与回放** | 完整记录每一步操作，可回放 | P1 |

---

### 3.2 M1. 爬虫漫游（P0 核心）

#### 3.2.1 漫游路径
机器人不是随机乱爬，而是按照预设路径有序扫描：

```
第 1 轮：自选股 → 逐只扫描
  ↓
第 2 轮：涨幅榜 → 找领涨股
  ↓
第 3 轮：板块行情 → 找热门板块
  ↓
第 4 轮：涨停雷达 → 看情绪/连板
  ↓
第 5 轮：龙虎榜 → 看主力资金
  ↓
第 6 轮：个股 K 线 → 深度分析候选股
  ↓
第 7 轮：交易面板 → 执行下单
  ↓
循环...
```

#### 3.2.2 漫游动画
- 从一个卡片"爬"到另一个卡片时，蜘蛛身体平滑移动（不是跳过去）
- 移动过程中，腿跟着身体一起动
- 到达新卡片后，停顿 2-3 秒"读取数据"，然后继续爬

#### 3.2.3 用户可干预
- 用户可以随时点某个卡片，机器人立刻切换过去（打断当前路径）
- 用户可以手动选中某只股票，机器人立刻去分析这只

---

### 3.3 M2. 数据采集（P0）

#### 3.3.1 采集的数据类型

| 卡片 | 采集什么数据 |
|------|-------------|
| **自选股** | 每只股票的：代码、名称、现价、涨跌幅、成交额、量比 |
| **涨幅榜** | 前 20 名：代码、名称、涨幅、所属板块 |
| **板块行情** | 板块名称、板块涨幅、领涨股、领涨股涨幅 |
| **涨停雷达** | 涨停家数、跌停家数、炸板率、连板高度、最高板 |
| **龙虎榜** | 买入金额、卖出金额、主力净流入、知名席位 |
| **个股 K 线** | 现价、MA5/MA10/MA20、MACD、RSI、成交量 |
| **分时图** | 现价、均价、量能分布、走势形态 |
| **交易面板** | 持仓、现金、可用资金 |

#### 3.3.2 数据标注
- 采集到的每个数据点，蜘蛛腿尖都有一个光点
- 光点颜色对应数据状态：
  - 🟢 绿色 = 利好信号（放量/上涨/主力流入）
  - 🔴 红色 = 利空信号（缩量/下跌/主力流出）
  - ⚪ 灰色 = 普通数据

---

### 3.4 M3. 分析决策（P0 核心）

#### 3.4.1 决策逻辑（三层漏斗）

```
第一层：粗筛（从几百只 → 十几只）
  - 涨幅 2%~7%（不追涨停、不买下跌）
  - 成交额 > 1 亿（有量）
  - 非 ST、非新股（排除风险股）
  ↓
第二层：精选（从十几只 → 3~5 只）
  - 所在板块涨幅 > 2%（板块助攻）
  - MA5 > MA10 > MA20（多头排列）
  - 量比 > 1.5（放量）
  - 主力资金净流入（龙虎榜/资金流向）
  ↓
第三层：确认（从 3~5 只 → 1~2 只）
  - K线形态：突破关键位/回踩确认
  - 分时走势：均价上方运行/量价配合
  - 市场情绪：涨停家数 > 30（环境支持）
```

#### 3.4.2 买卖信号定义

**买入信号（满足 3 条以上）：**
1. 涨幅 2%~7%
2. 成交额 > 1 亿
3. 量比 > 1.5
4. 板块涨幅 > 2%
5. MA 多头排列
6. 主力资金净流入

**卖出信号（满足任意 1 条）：**
1. 亏损 > 3%（止损）
2. 盈利 > 8%（止盈）
3. 跌破 MA10（趋势走坏）
4. 炸板/开板（情绪转弱）

#### 3.4.3 决策输出
每个信号都有明确的理由，例如：
> 🟢 买入：浦发银行(600000) — 放量上涨 + 银行板块领涨 + 突破 MA20 + 主力净流入 2.3 亿

### 3.5 M4. 视觉反馈（P0）

#### 3.5.1 蜘蛛视觉规范

| 元素 | 样式 |
|------|------|
| **蜘蛛身体** | 蓝色方块 + 三层发光光晕 |
| **蜘蛛腿** | 青色多关节弯曲折线（3-4 个弯） |
| **腿尖光点** | 圆点 + 多层光晕 |
| **买入信号** | 绿色腿 + 绿色光点 |
| **卖出信号** | 红色腿 + 红色光点 |
| **普通扫描** | 青色腿 + 粉色光点 |

#### 3.5.2 高亮标注
- 当前正在分析的股票：红色半透明高亮框
- 符合买入条件的：绿色半透明高亮框
- 符合卖出条件的：红色闪烁高亮框

#### 3.5.3 信息标签
每个数据点旁边都有标签，例如：
> 浦发银行 9.48 +3.27% 放量

### 3.6 M5. 自动交易（P1）

#### 3.6.1 交易流程
```
触发买入信号
  ↓
检查风控（仓位/现金/止损线）
  ↓
通过 → 自动下单（买 100 股）
  ↓
记录交易日志
  ↓
蜘蛛腿连到"买入"按钮，绿色高亮 2 秒
```

#### 3.6.2 半自动模式（默认）
- 触发信号后，不直接下单
- 弹出确认框："发现买入信号：XX 股票，理由：XXX，是否买入？"
- 用户点头 → 下单；用户忽略 → 10 秒后自动取消

#### 3.6.3 全自动模式（可选）
- 触发信号后直接下单，不需要确认
- 适合信任机器人的老用户

---

### 3.7 M6. 风控管理（P0）

| 规则 | 阈值 | 说明 |
|------|------|------|
| 最大持仓数 | 5 只 | 超过就不买了 |
| 单笔买入量 | 100 股 | 每只买一手 |
| 单只止损线 | -3% | 亏 3% 自动卖 |
| 单只止盈线 | +8% | 赚 8% 自动卖 |
| 总仓位上限 | 80% | 不满仓 |
| 急停按钮 | 🔴 红色 | 一键全部平仓 |

---

### 3.8 M7. 日志与回放（P1）

#### 3.8.1 实时日志
右下角滚动日志，每一步操作都有记录：
> 10:30:15 🕷 切换到自选股
> 10:30:16 🟢 发现买入信号：浦发银行 放量上涨
> 10:30:17 ✅ 自动买入 浦发银行 100 股 @ 9.48

#### 3.8.2 回放功能
- 当天的所有操作可以回放
- 像看视频一样，看机器人今天爬过哪些卡片、买了哪些股票
- 用于复盘："今天机器人买的票赚了还是亏了？为什么买？"

## 四、交互流程

### 4.1 启动流程
```
用户点"启动爬虫机器人"
  ↓
蜘蛛从屏幕边缘"爬"进来，停在屏幕中央
  ↓
顶部状态栏出现："🕷 AI 爬虫机器人 运行中"
  ↓
开始按预设路径漫游：自选股 → 涨幅榜 → 板块 → 涨停雷达 ...
```

### 4.2 发现机会的流程
```
机器人爬到"自选股"卡片
  ↓
蜘蛛腿伸到每只股票上，逐一点亮
  ↓
第 3 只股票（浦发银行）符合买入条件
  ↓
腿变绿 + 股票行变绿高亮
  ↓
日志弹出："🟢 买入信号：浦发银行 ..."
  ↓
（自动交易开着）→ 自动下单
（自动交易关着）→ 等用户确认
```

### 4.3 停止流程
```
用户点"停止"或按 Ctrl+Shift+S
  ↓
蜘蛛慢慢爬向屏幕边缘，消失
  ↓
顶部状态栏消失
  ↓
日志面板保留，可查看历史记录
```

## 五、非功能需求

| 项目 | 要求 |
|------|------|
| **性能** | 扫描一轮 < 3 秒，不卡 |
| **视觉** | 蜘蛛移动流畅，60fps |
| **内存** | 覆盖层不超过 50MB |
| **安全** | 自动交易前有确认（半自动模式） |
| **容错** | 某只股票数据读不到，跳过继续，不崩溃 |
