# TickGold 信号桥联调清单

> 用途：对「信号人工确认桥」做端到端联调，覆盖 **信号产生 → 灵动岛推送 → 人工改价改量 → 指令模板渲染 → 确认 / 驳回 → 唤起券商 → 审计留痕** 全链路。
> 边界：信号桥**只生成指令 + 人工确认 + 唤起券商，不自动成交**；AI 信号仅供参考，**不构成投资建议**。

## 0. 交易日历（2026 国庆）

- **10 月 1 日（周四）至 10 月 7 日（周三）休市，10 月 8 日（周四）起照常开市**。
- 因此本轮联调分两阶段：
  - **阶段一（休市，本清单第 1 节）**：用「手动新建 / 注入信号」做**离线全链路走查**，验证交互、模板、快捷键、审计、券商唤起。
  - **阶段二（10/8 开市，第 2 节）**：开启快脑 / 自动执行，做**真实盘中实时联调**。

---

## 1. 阶段一：离线全链路走查（休市可做）

> 入口：交易工具 → 「信号确认桥」卡片；工具行「手动新建」。

### 1.1 准备

- [ ] 安装并启动 **v2.4.1+**；打开「信号确认桥」卡片。
- [ ] 「设置 → AI → 信号桥」：
  - [ ] 打开**启用信号桥**开关；
  - [ ] 填写**默认券商**（如 同花顺）；
  - [ ] 配置**券商软件路径**（Windows 为 `.exe`，如 `C:\...\xiadan.exe`；macOS 为 `.app`）；
  - [ ] 默认动作先选「复制」，信号有效期保持 30 分钟；
  - [ ] 在「指令模板」框填入自定义模板（见 1.4），保存。

### 1.2 产生信号 + 灵动岛推送

- [ ] 点「手动新建」，填：方向=买入、代码=`600519`、名称=`贵州茅台`、价格=`1500.00`、数量=`100`、理由=`联调测试`，生成待确认单。
- [ ] **预期**：灵动岛**立即置顶并自动展开**，折叠态出现红色「买」胶囊 + 名称 + `1500.00 · 100`（v2.4.1 修复：手动信号也推送）。
- [ ] 再建一条：方向=卖出、另一代码（如 `300750 宁德时代`），预期卖出胶囊为卖出配色。
- [ ] 同票同向重复建单，预期被**去重**拒绝（提示已有相同方向待确认）。

### 1.3 待确认列表 + 改价改量

- [ ] 「待确认」Tab 出现两条，徽标计数正确；
- [ ] 在卡片内**改限价**（如 1499.50）、**改数量**（如 200）；
- [ ] 切换动作：复制 / 仅生成 / 唤起券商；切换目标券商；
- [ ] 价格偏离参考价超过阈值（默认 1.5%）时，应有价偏提示。

### 1.4 指令模板渲染

- [ ] 模板框填入，例如：
  `{sideEn} {code} {name} {price} x{vol} {amount} via {broker} {date}`
- [ ] 确认后**预期指令文本**：`BUY 600519 贵州茅台 1499.50 x200 299900 via 同花顺 2026-10-02`（金额=价×量，整数元）。
- [ ] 逐一核对占位符：`{side}` 买入/卖出、`{sideEn}`、`{code}`、`{name}`、`{price}` 两位小数、`{vol}`、`{amount}`、`{broker}`、`{date}`。
- [ ] 填入一个不存在的占位符（如 `{foo}`），预期**原样保留**；
- [ ] 清空模板保存，预期回退**内置默认**指令；点「恢复默认」同样生效。

### 1.5 快捷键

- [ ] 焦点不在输入框 / 下拉框时：
  - [ ] `Enter`：确认**最新一条**待确认；
  - [ ] `Ctrl/⌘+Enter`：确认并把动作置为**唤起券商**；
  - [ ] `R`：**驳回**第一条待确认；
- [ ] 全局 `Alt+S`：主窗口唤起、聚焦并打开信号桥（窗口最小化 / 失焦时验证）；
- [ ] 全局 `Alt+` `：老板键隐藏 / 恢复全部窗口，且不与 `Alt+S` 冲突。

### 1.6 确认 / 驳回 / 完成 / 唤起券商

- [ ] 「复制」动作确认后，指令写入剪贴板并提示；
- [ ] 「唤起」动作（或 Ctrl+Enter）确认后，**券商软件被拉起**（休市也能打开登录界面）；
- [ ] 确认后单据转「已确认」，在券商内成交后可手动标「已完成」；
- [ ] 驳回的单据进「已驳回」；
- [ ] 「清理过期」：把超过有效期（可临时调小到 1 分钟）的待确认单转为「已过期」。

### 1.7 审计留痕

- [ ] 每个状态流转（创建 / 确认 / 驳回 / 完成 / 过期）均在 `signal_audit` 有记录，含动作、明细、操作者、时间戳；
- [ ] 「全部」Tab 可回看所有单据与最终状态。

## 2. 阶段二：真实盘中实时联调（10/8 开市）

> 目标：验证真实行情下，快脑 / 自动执行**自动产生信号**并汇聚到信号桥。

### 2.1 开盘前

- [ ] 「设置 → AI」：选择快脑模式（规则脑 / 本地 Laya），健康检查通过；
- [ ] 确认**信号桥启用**、券商路径有效、默认动作与有效期合理；
- [ ] 自选 / 监控列表加入若干标的；确认模拟盘与信号桥的衔接配置。

### 2.2 盘中（9:15 集合竞价起）

- [ ] 9:15–9:25 集合竞价、9:30 连续竞价：快脑按周期输出概率；
- [ ] 触发买入（置信度 ≥ 阈值）/ 硬止损卖出 / SELL 时：
  - [ ] **不自动真实下单**，而是落待确认单、灵动岛实时推送（信号胶囊）；
  - [ ] 信号桥列表在事件触发后**立即**出现（非仅等 10s 轮询）；
- [ ] 人工改价改量 → 选券商 → 确认 → 唤起券商 → 在券商内完成真实成交；
- [ ] 同向去重、超期失效在盘中持续生效；
- [ ] 观察信号从产生到可操作的**端到端时延**（记录目标：灵动岛秒级、列表即时）。

### 2.3 盘中重点观察项

- [ ] 信号是否有**遗漏 / 重复 / 卡顿**；高频时灵动岛与列表是否稳定；
- [ ] 价格快速波动时，参考价 / 改价 / 价偏提示是否正确；
- [ ] Laya 不可达时是否自动降级为规则脑、信号不中断；
- [ ] 14:55（禁开仓时间）后买入信号是否被抑制、卖出 / 止损是否仍正常。

### 2.4 收盘后

- [ ] 当日所有信号与最终成交 / 驳回结果对账；
- [ ] `signal_audit` 全量可追溯；
- [ ] 问题与改进项回填到本文件「问题记录」。

## 3. 已知边界与风险

- 免费行情源存在延迟 / 限频 / 不可达，信号时间戳以本机接收为准，可能与真实成交时点有偏差。
- 券商软件路径、唤起方式因券商版本而异；唤起仅启动软件，**登录与下单仍需人工完成**。
- 本项目无券商牌照，**不提供真实委托下单、不做确定性预测 / 目标价**；维持五档盘口，不做 Level2 十档。
