# AI 爬虫机器人卡片 UI 改造设计文档

> 日期：2026-10-09
> 状态：已确认设计
> 目标：丰富 AI 爬虫机器人卡片的功能展示，支持分类实时日志显示

---

## 一、背景与目标

### 1.1 现状
当前 `SpiderBot.vue` 卡片采用简单的上下布局：
- 顶部：控制按钮（启动/停止/全屏/自动交易/急停）
- 中部：蜘蛛 SVG 可视化
- 底部：两个简单日志面板（抓取日志 + 交易日志）

功能展示不够丰富，日志分类简陋，信息密度低。

### 1.2 目标
- **丰富功能展示**：将策略、绩效、市场情绪、风控等数据在卡片中直观展示
- **日志分类系统**：按功能分为 6 大类，支持 Tab 切换过滤
- **实时性**：日志实时滚动、计数徽章跳动、新日志高亮
- **信息密度**：采用左右分栏 + 底部日志的仪表盘布局

---

## 二、整体布局

### 2.1 布局结构
采用 **科技仪表盘布局**（方案A），从上到下 5 个区域：

```
┌─────────────────────────────────────────────────────┐
│  顶部控制栏（启动/停止/模式/急停/状态）               │  ~10%
├──────────────────────────┬──────────────────────────┤
│                          │  策略 & 绩效             │
│   🕷 蜘蛛可视化舞台      ├──────────────────────────┤  ~50%
│   (SVG 主舞台)           │  市场情绪仪表盘          │
│                          ├──────────────────────────┤
│                          │  风控状态                │
├──────────────────────────┴──────────────────────────┤
│  📡 智能日志中心（6分类 Tab + 实时滚动）              │  ~30%
├──────────────────────────────────────────────────────┤
│  底部数据源标签（已启用的数据源高亮）                  │  ~10%
└──────────────────────────────────────────────────────┘
```

### 2.2 卡片尺寸
- 推荐 span：3
- 推荐 rspan：3~4
- 最小可工作尺寸：span=2, rspan=2（日志区会压缩但仍可用）

## 三、各区域详细设计

### 3.1 顶部控制栏

#### 控件列表（从左到右）：
1. **标题**：🕷 AI爬虫机器人
2. **启动/停止按钮**（主按钮）
   - 停止状态：绿色「▶ 启动爬虫」
   - 运行状态：红色「⏸ 停止爬取」+ 脉冲动画
3. **半自动按钮**
   - 琥珀色，ON 时发光
   - 与全自动互斥
4. **全自动按钮**
   - 品红色，ON 时发光
   - 与半自动互斥
5. **急停按钮**
   - 红色「🛑 急停」，悬停放大
   - 靠右对齐

#### 状态行（第二行）：
- 📍 当前扫描卡片名（青色高亮）
- ⟳ 已扫描轮次（数字跳动动画）
- 📊 总步数（累计）

- 核心眼睛随扫描方向微动

- 扫描光束：当前目标节点周围辐射光束（已实现，保留）

### 3.4 智能日志中心（核心功能）

#### 6 大分类

| 分类 | 图标 | 颜色 | 包含内容 |
|------|------|------|----------|
| 全部 | 📋 | 金色 | 所有日志混合（默认） |
| 扫描 | 🔍 | 青色 | 数据采集：自选股、涨幅榜、板块、大盘、雷达等 |
| 信号 | 🎯 | 品红 | 买卖信号生成、评分结果、因子列表 |
| 交易 | 💰 | 红/绿 | 交易执行、信号桥、持仓变化 |
| 风控 | 🛡️ | 琥珀色 | 风控拦截、止盈止损、仓位检查 |
| 系统 | ⚙️ | 蓝灰色 | 启停、策略切换、切卡、模式切换 |

#### 日志条目结构
```
┌──┐  HH:MM:SS  [分类标签]  标题
│图标│      副标题/详细信息
└──┘      [附加数据行（可选）]
```

#### 交互特性
- ✅ **自动滚动**：新日志从顶部插入；手动上滚暂停，滑回顶部恢复
- 🏷️ **分类过滤**：顶部 Tab 切换，每类独立保留 50 条
- 🔢 **计数徽章**：每 Tab 右上角显示条数，新到达时数字跳动
- ✨ **新日志提示**：非当前 Tab 有新日志时微闪烁
- 🎨 **颜色编码**：6 分类 6 配色，左侧图标条 + 文字颜色
- 🔍 **点击展开**：点击条目展开完整详情（信号日志显示全部因子）
- 🗑️ **清空日志**：右上角菜单内「清空日志」
- ⏸️ **暂停滚动**：右下角暂停按钮

#### 数据结构
```typescript
interface SpiderLogEntry {
  id: number;
  time: string;                    // HH:MM:SS
  category: 'scan' | 'signal' | 'trade' | 'risk' | 'system';
  icon: string;                    // emoji
  title: string;                   // 主标题
  subtitle?: string;               // 副标题
  detail?: string;                 // 详情（展开显示）
  code?: string;                   // 股票代码
  name?: string;                   // 股票名称
  price?: number;                  // 价格
  pct?: number;                    // 涨跌幅
  score?: number;                  // 评分
  signals?: string[];              // 触发因子列表
  amount?: number;                 // 交易金额
  qty?: number;                    // 交易数量
  side?: 'BUY' | 'SELL';           // 买卖方向
  reason?: string;                 // 原因/理由
  level: 'info' | 'success' | 'warn' | 'error';
  expanded?: boolean;              // 是否展开
}
```

## 五、技术实现要点

### 5.1 组件结构
全部在 `SpiderBot.vue` 内重构，不拆分为多文件（保持单文件组件的简洁性）。

### 5.2 状态管理
- 复用 `useSpiderBotEngine()` composable
- 新增 `logs` 状态：`Ref<SpiderLogEntry[]>`
- 新增 `activeLogTab` 状态：当前选中的日志分类
- 从 engine 的 `logs` 迁移到更丰富的结构化日志

### 5.3 日志系统改造
- 重构 `addLog` 函数，支持结构化日志
- 按分类过滤使用 `computed`
- 自动滚动：使用 `scrollTop` + `MutationObserver` 或 nextTick

### 5.4 动画实现
- 数字跳动：CSS transition + keyframes
- 新日志高亮：CSS animation flash
- Tab 闪烁：CSS animation ping
