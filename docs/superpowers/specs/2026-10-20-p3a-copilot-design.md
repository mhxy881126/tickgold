# P3-a 设计：Copilot 自然语言 → 条件单草稿

> 日期：2026-10-20　|　基线：P2-b2 已合并 `9a5480f`
> 范围：规则解析（代码/方向/触发/数量）+ 预览确认；LLM 抽取留 P3-a2。

## 目标

作战台头部增加 Copilot 输入框：输入「600519 跌破1680 买入100股」→ 解析为条件单草稿（代码、名称、方向、触发叶子、数量）→ 用户确认后调用现有 `coCreate` 落地；不自动提交、不直接下单。

## 语法（v1）

| 元素 | 支持写法 |
|---|---|
| 代码 | 6 位数字，可选 `sh`/`sz` 前缀（大小写不限） |
| 方向 | 买入/买/加仓 → BUY；卖出/卖/减仓/止盈/止损 → SELL |
| 价格触发 | 跌破/低于/≤ X → `price lte`；涨到/突破/高于/≥ X → `price gte` |
| 涨跌幅触发 | 涨幅/涨 X% → `pct gte`；跌幅/跌 X% → `pct lte` |
| 数量 | `N股`；`N手` ×100；缺省 100，必须 100 整数倍 |

- 同时给出价格与涨幅时，价格优先（与物化方向互斥规则一致）。
- 无法解析 → 中文错误，不产生草稿。
- 名称从行情 store 补全；补不到显示代码。

## 交互

`CopilotBar.vue` 挂在作战台头部：

- 输入 `data-testid="copilot-input"` + 「解析」`copilot-parse`；
- 预览 `copilot-preview`：`贵州茅台 600519 · 买入 100 股 · 价格 ≤1680.00`；
- 「创建条件单」`copilot-confirm` → `coCreate({code,name,side,trigger,vol,autoConfirm:true,ttl:"day"})` → toast + 刷新指令列表；
- 「取消」`copilot-cancel` 收起；
- 解析失败显示中文错误 `copilot-error`。

## 验收

1. 四种触发写法（价格上/下、涨幅上/下）都能解析；`N手` 正确 ×100；非法数量/无代码报中文错误。
2. 确认后条件单出现在「本地条件单」，方向/触发/数量正确；不产生委托。
3. 单测覆盖 8 类输入；e2e 走一遍输入→预览→确认→fake `co_create` 断言。
4. 不改下单/风控路径，不依赖 LLM/API Key。

## 风险

- 中文口语变体多，v1 只覆盖高频句式；未识别时明确提示「请用：代码 + 跌破/涨到 + 价格 + 买/卖 + 数量」。
- 名称解析依赖行情缓存，缓存缺失时仅显示代码。
