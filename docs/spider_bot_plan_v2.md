# AI 爬虫机器人 - 完整实现方案 v2

## 一、核心定位

不是"显示蜘蛛动画"，而是**真正自主决策的 AI 交易机器人**。

蜘蛛只是视觉反馈，核心是：
- 自主扫描多个卡片（自选股/板块/涨停雷达/榜单）
- 自主读取实时数据
- 自主分析判断（K线/量价/情绪）
- 自主触发买卖信号
- 自动执行交易

## 三、自主决策流程

### 第 1 步：自选股扫描
```
遍历自选股列表（6 只）
  ↓
对每只股票：
  1. 读实时价格、涨跌幅、成交额
  2. 判断是否符合买入条件：
     - 涨跌幅 2% ~ 7%（不追涨停）
     - 成交额 > 1 亿（有量）
     - 成交量比 > 1.5（放量）
  3. 符合条件 → 标记为"候选买入"
  4. 不符合 → 跳过
```

### 第 2 步：K线深度分析
```
切换到 K 线图卡片（选中当前股票）
  ↓
分析：
  1. MA5 > MA10 > MA20 → 多头排列（强势）
  2. 今日放量突破 MA20 → 买入信号
  3. 今日跌破 MA10 → 卖出信号
  4. RSI > 80 → 超买（不追）
  5. RSI < 20 → 超卖（观察）
```

### 第 3 步：市场情绪判断
```
切换到涨停雷达卡片
  ↓
判断：
  1. 涨停家数 > 50 → 市场情绪亢奋（可积极买入）
  2. 涨停家数 < 20 → 市场冷清（谨慎）
  3. 连板高度 > 5 板 → 赚钱效应好（可追龙头）
  4. 炸板率 > 30% → 情绪不稳（减仓）
```

### 第 4 步：板块扫描
```
切换到板块卡片
  ↓
判断：
  1. 当前股票所在板块涨幅 > 2% → 板块助攻（可买入）
  2. 板块领涨股已涨停 → 龙头已封板（可买跟风）
```

### 第 5 步：执行交易
```
如果信号 = 买入：
  1. 检查仓位（最多持 5 只）
  2. 检查现金（买入 100 股）
  3. 调用 paperStore.buy(code, name, price, 100)
  4. 蜘蛛腿连到买入按钮，高亮绿色

如果信号 = 卖出：
  1. 检查持仓（有没有这只股票）
  2. 调用 paperStore.sell(code, price, 持仓数量)
  3. 蜘蛛腿连到卖出按钮，高亮红色
```

## 四、分析策略细则

### 买入条件（满足任意 2 条）
| 条件 | 阈值 | 说明 |
|------|------|------|
| 涨跌幅 | 2% ~ 7% | 不追涨停，不买下跌 |
| 成交额 | > 1 亿 | 有量才能涨 |
| 量比 | > 1.5 | 放量 |
| MA 多头 | MA5 > MA10 > MA20 | 趋势向上 |
| 突破 | 今日突破 MA20 | 关键位置突破 |
| 板块 | 所属板块涨幅 > 2% | 板块助攻 |

### 卖出条件（满足任意 1 条）
| 条件 | 阈值 | 说明 |
|------|------|------|
| 止损 | 亏损 > 3% | 跌破止损线 |
| 止盈 | 盈利 > 8% | 落袋为安 |
| 破位 | 跌破 MA10 | 趋势走坏 |
| 超买 | RSI > 80 | 涨太多了 |

### 风控规则
- 最多同时持有 5 只股票
- 每只买 100 股
- 总仓位不超过 80%
- 单只亏损超过 5% 强制止损
