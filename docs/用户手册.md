## 一、简介

TickGold 是面向个人投资者的跨平台 A 股盯盘终端，核心能力包括：

- **实时盯盘**：自选、榜单、板块、资金流、五档盘口，多数据源容灾、增量刷新；
- **分时复盘**：双击 K 线蜡烛进入复盘工作台，逐分钟回放、多日分时叠加、量比副图；
- **智能预警**：价格边沿、跳水、封板 / 炸板、换手率、成交额等多类条件，触发即通知 + 提示音；
- **辅助工具**：模拟交易、投资计算器、数据导出、盯盘日记、条件选股、F10、经济 / 新股日历；
- **个性化与可访问性**：9 套主题、界面缩放、高对比模式、完整快捷键与新手引导。

> TickGold 仅用于看盘与模拟交易，**不提供真实下单**。

## 二、安装与卸载

### Windows

1. 在 [Releases](https://github.com/mhxy881126/tickgold/releases/latest) 下载 `TickGold_<版本>_x64-setup.exe`；
2. 双击运行，按向导完成安装（默认安装到当前用户目录，无需管理员权限）；
3. 安装器会在安装前**自动结束正在运行的 TickGold**（含主进程、WebView2 子进程与托盘进程），支持直接覆盖升级。

**SmartScreen 提示**：安装包暂未做代码签名，首次运行可能出现「Windows 已保护你的电脑」。点击「更多信息 → 仍要运行」即可。

**覆盖安装 / 升级**：直接运行新版安装包即可，无需先卸载。若你曾以「管理员身份」运行过 TickGold，请先从托盘右键完全退出，再运行安装器。

**卸载**：从「设置 → 应用 → 已安装的应用」中卸载。卸载结束时会询问**是否同时删除个人数据**：

- 选「是」：删除自选股、布局、预警、数据库与缓存（不可恢复）；
- 选「否」（默认，静默卸载也选否）：保留个人数据，下次安装后自动恢复。

### macOS

1. 下载与芯片对应的 `.dmg`：Apple 芯片（M 系列）选 `aarch64`，Intel 选 `x64`；
2. 挂载后将 TickGold 拖入「应用程序」；
3. 首次运行若提示无法验证开发者，可到「系统设置 → 隐私与安全性」中点击「仍要打开」。

升级时直接用新版 `.dmg` 覆盖即可，个人数据保留。

## 三、界面总览

TickGold 采用「灵动岛悬浮条 + 主工作台」双形态。

### 灵动岛悬浮条

常驻屏幕顶部的小条，显示当前关注标的的名称、价格与涨跌幅；点击可展开主窗口。在全局快捷键 `Alt + ` `（反引号，Tab 上方）可快速显示 / 隐藏（老板键）。

### 主工作台

- **顶栏**：Logo、全局搜索框、实时状态、布局入口、设置、检查更新，以及窗口控制按钮；
- **功能分组栏**：大盘总览 / 盯盘模式 / 情绪异动 / 板块题材 / 个股行情 / 交易工具，点击切换不同的卡片布局；
- **时段页签**：集合竞价、早盘 9:30、午盘、尾盘 14:30、盘后复盘，按交易时段组织布局；
- **卡片网格**：每个卡片是一个独立功能模块，右上角可固定 / 最小化 / 关闭；
- **卡片聚焦**：点击卡片可进入主从聚焦（放大查看），按 `Esc` 退出。

### 布局

- 支持在不同功能分组与时段间切换，布局会自动保存；
- 部分视图支持自由布局（自由拖拽卡片位置）。

## 四、自选股管理

「自选股」卡片用于管理你关注的标的。

- **搜索添加**：在顶部搜索框或自选卡片中输入代码 / 名称 / 拼音首字母，回车添加；
- **分组管理**：新建、重命名分组，在分组间移动标的；
- **删除**：在标的上操作移除；
- **快速看图**：点击任一标的，K 线图与盘口联动切换。

自选数据保存在本地数据库，断网仍可查看列表。

## 五、行情与盯盘

- **榜单**：涨幅 / 跌幅 / 成交额等排行榜，虚拟滚动、分页加载全市场标的；
- **市场宽度 / 情绪**：上涨 / 下跌 / 平盘 / 涨停 / 跌停家数、涨停雷达、炸板率等，快速感知盘面温度；
- **板块**：板块行情、板块异动、板块热力图，点击板块查看成分股；
- **资金流向**：主力 / 大单 / 中单 / 小单净流入；
- **五档盘口**：展示买卖五档价格与挂量（实时行情源）；
- **短线精灵**：实时推送拉升、跳水、大单、封板等异动。

卡片在不可见、窗口最小化时会**智能暂停轮询**，恢复即刷新，节省资源。

## 六、K 线、画线与分时复盘

### K 线

打开「K 线图」卡片，可切换周期（分时 / 日 / 周 / 月等），主图与副图支持常用技术指标，顶部显示今开、最高、最低、成交量、振幅等数据。

### 画线工具

K 线左上角提供可收起的画线工具条，支持线段、射线、直线、水平线、平行线、通道线、黄金分割、标签等多种画线；按「股票 + 周期」分别保存，切换标的 / 周期自动恢复。画线过程中按 `Esc` 结束当前画线。

### 分时复盘（复盘工作台）

**双击任意一根日 K 蜡烛**打开历史分时复盘工作台：

- **历史分时回放**：播放 / 暂停，进度条可拖动，支持 1 / 2 / 4 / 8 倍速逐分钟回放，时间、价格、均价、涨跌幅随定位联动；
- **多日分时叠加**：2 / 3 / 5 日按交易分钟轴精确对齐，选中日加粗、其余日彩色区分，附各日昨收虚线与图例；
- **分时量比副图**：当分钟成交量 ÷ 多日同时段均量，附 1.0 基准线；
- **交易时段分段着色**：集合竞价金色窄区、上午淡红、下午淡蓝、午休分隔虚线。

> 免费行情源不提供历史五档盘口与 9:25 集合竞价分钟点，故复盘以该分钟的价格 / 均价 / 量 / 涨跌幅为准。

## 七、预警

「预警管理」卡片用于创建和管理价格 / 异动预警。

- **条件类型**：价格上穿 / 跌破（边沿触发）、跳水、涨停 / 跌停封板、涨停炸板、换手率、成交额；
- **触发方式**：条件满足当轮才触发（不重复报警），随后发送系统通知，可伴随提示音（可开关）；
- **触发历史**：预警卡片「触发历史」Tab 可回看历次触发，也可清空；
- **启用 / 停用**：可整体启用或暂时关闭预警。

预警规则与触发事件均持久化在本地数据库。

## 八、交易工具与其他功能

- **模拟交易**：虚拟资金买卖，记录持仓与成交流水，用于练习（非真实下单）；
- **投资计算器**：盈亏（佣金 / 印花税 / 过户费、保本价）、仓位管理、风报比、补仓成本、复利、黄金分割等；
- **数据导出**：自选 / 榜单 / K 线 / 模拟持仓 / 成交流水 / 日记 / 预警等，导出 CSV（带 BOM，Excel 不乱码）或 JSON；
- **盯盘日记**：记录复盘心得，支持标签；
- **条件选股**：按技术形态 / 指标条件筛选标的；
- **F10**：个股资料；
- **日历**：经济日历、新股申购 / 上市日历。

## 九、设置

点击顶栏「设置」（或按 `Ctrl/⌘ + ,`）打开设置对话框，包含四个页签：

- **外观**
  - 开机自动启动开关；
  - 9 套配色主题，选择后立即生效并记住；
  - 界面缩放：紧凑 / 标准 / 大 / 特大；
  - 高对比模式开关；
- **数据**：本地时序采集状态；
- **日志（诊断日志）**：合并前后端日志，按级别筛选、一键导出 `.txt`；
- **关于**：版本与技术栈信息，可「重新查看新手引导」。

## 十、自动更新

点击顶栏「检查更新」（或按 `Ctrl/⌘ + U`）打开更新对话框。

- **多镜像容灾**：检查与下载均在 ghproxy / gh-proxy / 官方直连之间自动选择，国内网络可正常升级；
- **信息透明**：显示版本对比、更新说明、下载进度（百分比、MB、速度）；
- **签名校验**：安装包经 minisign 签名校验，校验通过才会安装，对话框会明确提示「签名校验通过」；
- **安装前备份**：下载完成、开始安装前会自动备份数据库（保留最近 5 个）；
- **失败处理**：下载失败可重试，或一键打开手动下载页。

若启动时检测到数据库损坏，应用会自动恢复最近一次备份并重启；详见下一节。

## 十一、数据与隐私

TickGold 为**本地优先**，所有个人数据保存在本机，不向任何服务器上传你的自选、预警或交易记录。

### Windows 数据目录

- 应用数据：`%APPDATA%\com.stockdock.desktop`
  - 数据库：`stock-dock.db`（自选、布局、预警、日记等）；
  - 数据库备份：`backups\stock-dock-<版本>-<时间>.db`（保留最近 5 个）；
  - K 线缓存：`cache\kline\<代码>_<周期>.json`；
- WebView 数据：`%LOCALAPPDATA%\com.stockdock.desktop\EBWebView`。

### 备份与迁移

- **备份**：可直接复制 `stock-dock.db`；更新前应用也会自动备份；
- **迁移到新电脑**：安装同版本 TickGold 后，将 `stock-dock.db` 复制到对应数据目录即可；
- **损坏恢复**：启动检测到数据库损坏时，会把损坏库重命名为 `stock-dock.corrupt-<时间>.db` 留证，并自动恢复最近备份；若无备份则提示错误。

### 卸载清理

卸载时选择删除个人数据，会移除上述 `%APPDATA%` 与 `%LOCALAPPDATA%` 下的应用目录；选择保留则数据不丢失。
