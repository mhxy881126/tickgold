# 数据源说明

TickGold 的行情来自互联网**公开、免费**的行情接口，采用「多数据源容灾」：以腾讯行情为主，新浪、东方财富作为备份与功能补充，巨潮资讯用于新股数据。单源超时或异常时自动切换，并配合熔断与退避，避免请求雪崩。

> 这些接口均为数据厂商面向网页 / App 公开的接口，**并非为第三方提供的授权商业服务**。TickGold 仅做个人学习与盯盘用途，请控制请求频率，勿用于商业转售。

## 三、历史分时返回结构

`day/query` 一次返回**最近 5 个交易日**的分钟数据：

```jsonc
{
  "data": {
    "sh600246": {
      "data": [
        {
          "date": "20260925",
          "data": [
            "0930 6.81 12345 8400000",   // HHMM 价格 累计成交量 累计成交额
            "0931 6.82 13002 8850000"
            // ... 每天约 267 行
          ]
        }
        // ... 共 5 天
      ]
    }
  }
}
```

- 每行以空格分隔：`HHMM`（分钟时刻）、`价格`、`累计成交量`、`累计成交额`；
- 时间轴覆盖上午 09:30–11:30、下午 13:00–15:00，每天约 267 个分钟点；
- 多日叠加时按 `HHMM` 在交易分钟轴上精确对齐。

## 四、盘口 / 资金字段口径（v2.28）

免费五档盘口与资金流字段在各行情软件间定义略有差异，TickGold 统一采用以下口径：

### 盘口深度（免费五档，非 Level-2）

| 字段 | 定义 |
| --- | --- |
| 五档买 / 卖量 | 买一~买五、卖一~卖五挂单量合计（手） |
| 委比 | `(五档买量 − 五档卖量) / (五档买量 + 五档卖量) × 100%`，范围 −100%~100%；正值买盘挂单占优 |
| 委差 | 五档买量 − 五档卖量（手） |
| 外盘 | 开盘至今以卖方报价主动成交（主动买）的累计成交量（手），腾讯字段 f[7] |
| 内盘 | 开盘至今以买方报价主动成交（主动卖）的累计成交量（手），腾讯字段 f[8] |

- 内外盘为**累计**口径，反映当日主动买卖力量；东财 / 新浪无该字段时，后端自动以腾讯快照补全；
- 委比衡量的是**挂单**强弱，内外盘衡量的是**已成交**主动性，两者方向可能不一致；
- 五档挂单可随时撤改，委比不等于真实买卖意图。

### 资金流四档（东方财富 fflow 口径）

| 档位 | 含义（按单笔成交金额划分） |
| --- | --- |
| 超大单 | 机构 / 大户级别单笔（东财阈值，通常 ≥100 万元） |
| 大单 | 通常 20 万~100 万元单笔 |
| 中单 | 中等单笔（通常 4 万~20 万元） |
| 小单 | 散户小单笔 |
| **主力净流入** | **超大单净流入 + 大单净流入** |

- 个股、大盘全景、板块排名三处均使用同一 fflow 口径，数值可交叉对照；
- 大盘全景 = 上证（secid `1.000001`）+ 深证成指（`0.399001`）分时 / 多日数据按时间对齐求和；
- 档位阈值由东方财富按成交单金额判定，TickGold 不自行划分；不同软件因算法差异（逐笔撮合方向、统计范围）数值会有出入，属正常现象；
- 资金流为免费数据，存在延迟与缺失，分时拉取失败时全景页安全降级（仅展示多日趋势）。

### 短线精灵异动阈值（v2.28 可配）

| 检测项 | 默认阈值 | 说明 |
| --- | --- | --- |
| 急速拉升 / 猛烈打压 | 相邻 5 秒快照涨跌幅变化 ±0.5% | 基于日内涨快照差值，非区间最高价差 |
| 大笔买入 / 卖出 | 相邻快照成交额增量 ≥ 1000 万元 | 方向按快照间价格涨跌判定（非逐笔主动方向） |
| 放量异动 | 量比上穿 3.0 | 仅上穿瞬间触发一次 |
| 涨停 / 跌停封板、开板 | 按板块涨跌幅限制估算涨停价 | 主板 ±10%、创业板/科创板 ±20%、北交所 ±30%、ST ±5% |

阈值在「短线精灵 · 阈值」中修改，持久化于本地 meta，运行中保存后下一快照生效。大单为**快照区间成交额**口径而非逐笔成交，与资金流四档口径不同，不可直接对比。

## 五、已知限制（免费源）

- **不保证实时性与准确性**：免费接口存在延迟、字段缺失或偶发错误，不应作为交易唯一依据；
- **无历史五档盘口**：仅当日实时五档，历史回放不提供逐笔 / 五档；
- **无 9:25 集合竞价分钟点**：历史分时从 09:30 开始；
- **历史分时仅最近 5 个交易日**；
- **复权数据有限**：日 K 默认不复权，部分接口可切换前 / 后复权；
- **北交所 / 部分指数支持不完整**；
- 接口可能随时变更、限流或停用，需要在数据层做容错。

## 六、本地数据目录与缓存

抓取的数据与个人设置保存在本地（详见[用户手册 · 数据与隐私](用户手册.md#十一数据与隐私)）：

- Windows 应用数据：`%APPDATA%\com.stockdock.desktop`
  - SQLite 数据库：`stock-dock.db`（自选、分组、布局、预警、预警事件、日记、meta 设置等）；
  - 数据库备份：`backups\stock-dock-<版本>-<时间>.db`（保留最近 5 个）；
  - K 线缓存：`cache\kline\<代码>_<周期>.json`；
- WebView 数据：`%LOCALAPPDATA%\com.stockdock.desktop\EBWebView`。
