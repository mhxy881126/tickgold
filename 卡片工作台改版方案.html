// 需求 1 · 自定义编排

流体磁贴：打破固定行列，卡片成为可自由拖拽、磁吸对齐、自由缩放的磁贴；一键流体整理，布局可序列化保存。对应 方案 A。

// 需求 2 · 菜单与切换

自适应 Bento：可折叠图标导轨 + Mega 面板、⌘K 命令中心、底部卡片坞，场景切换FLIP 平滑重排。对应 方案 C。

// 需求 3 · 交易系统

交易指挥舱：账户资金、信号确认桥、逐笔与持仓、一键下单与 Kill Switch 同屏，打通信号→确认→指令。对应 方案 B。

A

卡片不再被行列锁死——点「进入编排」，磁贴可自由拖拽、磁吸对齐、右下角缩放；靠近其它磁贴边缘时弹出青色辅助线，「一键整理」像流体一样重新装箱。

// ① 编排工具条

常驻顶栏：添加磁贴、一键整理、密度（宽松/标准/紧凑）集中在工具条，不再藏在布局下拉里，编排开关一键进出。

// ② 磁吸与缩放

磁吸规则：拖动时检测画布边、其它磁贴边/中线，8px 内吸附并显示青色辅助线；右下角缩放，尺寸吸附 1/12 列单元。

// ③ 整理与保存

流体装箱：一键整理按视觉顺序 shelf-pack 填满缝隙、FLIP 滑入；仅保存每卡 {x,y,w,h} 与密度，多套命名布局并存、可重置。

B

交易指挥舱 · 大盘盯盘交易系统

// ① 账户风控条

常驻可视：总资产、可用、市值、当日盈亏与仓位占比同屏；单票/总仓位上限提交前校验，Kill Switch 二次确认全撤。

// ② 信号人工确认

人工在环：BUY/SELL 一律落「待确认」，改价、改量、选券商后才生成指令，系统不自动成交，四态全程留痕。

// ③ 快捷与模拟

只生信号：中部 BUY/SELL 快捷操作只生成待确认信号；先跑通模拟盘闭环，QMT 以唤起/复制辅助，真实委托在券商端确认。

// ① 可折叠导轨

菜单分层：64px 图标态点击弹 Mega 面板；212px 展开态手风琴选卡，分组已开卡片数红色角标，一眼掌握。

切换无跳变：增删卡、切场景用 FLIP 记录新旧位置，卡片惯性滑位；底部卡片坞点击聚焦闪烁、× 快速移除。

点「进入编排」进流体画布：拖拽磁吸、右下角缩放吸附 1/12 列、一键整理、密度三档；保存为命名布局，退出未保存即丢弃。
