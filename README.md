# TickGold

<img src="branding/tickgold-logo-2048.png" alt="TickGold logo" width="96" />

> 为「交易者盯盘」而生的跨平台 A 股桌面终端。比传统交易软件更轻、更快、更专注盘中。
> **Tauri 2.0（Rust）+ Vue 3 + TypeScript + Pinia + ECharts**，一套代码同时发布 Windows 与 macOS（Apple Silicon / Intel）。

## 特性一览

**卡片化动画工作台**
- 所有功能模块都是可自由开关的「卡片」：**顶部功能 Dock** 一键打开 / 关闭
- 打开缩放模糊→清晰、关闭缩小淡出、卡片间 FLIP 平滑让位
- **顶部功能 Dock（macOS Dock 感）**：水平排布、按功能域分组（总览 / 盯盘 / 板块 / 行情 / 选股交易 / 工具），鼠标滑过相邻图标联动放大上浮，开启项金色高亮；**功能项超宽时鼠标滚轮即横向滚动，两端出现左右箭头快速翻页**，最右侧布局组始终可达
- **通用装箱布局引擎**：任意数量卡片都自动均匀铺满工作台——整数网格坐标、互不重叠、不留空洞；手动增删卡片时自动退出固定 Bento 回到自由网格，彻底杜绝卡片增多后被挤成窄列 / 重叠的布局崩溃
- **卡片自由布局（随意拖拽摆放）**：「布局 → 自由拖拽布局」进入后，按住卡片标题栏可把它拖到画布**任意位置**，松手自动碰撞避让、绝不重叠；卡片位置随命名布局一起保存，可一键「恢复自动布局」回到整齐网格；自动模式下也支持同区重排、主干 / 侧栏跨区移动，落点高亮、动画流畅
- **布局自动保存**：当前布局实时记忆；顶栏「布局」可保存多套命名布局、随时切换、一键恢复默认
- 多套模式预设（盯盘 / 选股 / 全功能 / 纯图表）一键切换，置于 Dock 最右侧

**时段驾驶舱（Time-Session Cockpit）**
- 工作台顶部时段 Tabs：**集合竞价 / 早盘 / 午盘 / 尾盘 / 盘后复盘**，右侧实时时钟（秒），自动判定并高亮当前所处时段、启动即自动进入
- 一套 8 卡片 Bento 不规则网格，一屏看全盘面全局：
  - **板块热力图大卡**（行业 / 概念，面积=规模、颜色=涨跌）
  - **市场情绪**紧凑卡（封板率环 + 上涨 / 下跌 / 涨停 / 跌停 + 连板高度 / 炸板率）
  - **涨停雷达**（连板梯队）、**主力资金**、**异动实时流**
  - **题材轮动**标签云（概念板块按涨幅着色、按热度定字号，点击联动领涨股）
  - **涨跌分布**对称红绿柱（涨跌幅十档家数）
  - **盘中快讯**（新浪 7x24 全球直播，45s 自动刷新、滚动加载更多、点击查看原文）
- 时段切换 / 卡片开关全程沿用卡片化缩放模糊动画，关闭卡片即恢复默认工作台

**全市场榜单（覆盖沪深京 5000+ 只）**
- 涨幅 / 跌幅 / 成交额榜单，**滚动到底自动加载下一页**，可一直加载到全部股票
- 每行最新价、涨跌幅、成交额，**「+」一键加入自选（已加显示 ✓）**，点击联动 K 线 / 盘口

**自选股分组管理**
- 多分组（新建 / 重命名 / 删除），每行「⇄」即可把股票**移动到其他分组**（弹层自动向上 / 向下、不被卡片裁切）、「×」一键移出；搜索代码 / 名称回车即加入当前分组
- 自选股的新增 / 删除 / 移动 / 分组改动会**实时同步到灵动岛**，无需重开

**市场宽度（涨跌分布）**
- 涨跌家数分时：上涨 / 下跌家数随交易分钟实时曲线，盘中赚钱效应一目了然
- 涨跌分布直方图：涨跌幅 10 档（≥7% 至 ≤-7%）家数，红涨绿跌、深色为高弹性
- 顶部实时统计上涨 / 下跌 / 平盘、涨停 / 跌停 / 炸板家数与炸板率

**K 线 / 分时（ECharts）**
- 日 / 周 / 月 K：红涨绿跌蜡烛 + MA5/10/20 + 成交量副图 + dataZoom
- 当日分时图、周期切换、十字光标、自适应缩放

**五档盘口 · 资金流向 · 板块行情**
- 五档买卖盘 + 今日概览（开 / 高 / 低 / 量 / 额）
- 个股资金流向：主力 / 散户净流入、特大 / 大 / 中 / 小单四档，实时轮询
- 板块行情：申万行业 / 概念板块，按涨幅 / 净流入排序，领涨股点击联动

**条件选股 / 智能选股器**
- 技术形态：均线多头、MACD 金叉、放量上涨、突破新高、站上 20 日线
- 行情 / 基本面区间：价格、涨跌幅、换手率、量比、振幅、PE、PB、流通市值
- 6 套一键预设（均线多头 / MACD 金叉 / 放量突破 / 当日强势 / 低估值 / 大盘蓝筹），结果点选联动

**涨停雷达（连板 / 炸板 / 市场情绪）**
- 全市场扫描（沪深京 5000+），实时统计涨停 / 跌停 / 炸板家数、炸板率与上涨 / 下跌家数
- 连板梯队：**含首板（1 板）到最高标完整梯队**，板高分档配色、最高标金色高亮，股票 chip 带价格，首板可折叠 / 展开
- 市场情绪温度（冰点 / 低迷 / 中性 / 活跃 / 亢奋）仪表盘，量化盘面赚钱效应

**板块资金热力图 · 板块异动看板**
- 板块热力图（treemap）：面积 = 成交规模（可切 |净流入|），颜色 = 涨跌幅；**滚轮缩放、拖拽平移**，大方块多显示净流入，行业 / 概念切换，点击联动领涨股
- 板块异动看板：打开即展示**当前领涨 / 资金青睐 / 走弱板块快照**（非交易时段也有内容并提示定格），盘中实时 diff 捕捉拉升 / 跳水（≥ 0.3%）、抢筹 / 出逃（≥ 0.3 亿），支持筛选 / 暂停 / 清空

**短线精灵 / 异动实时流**
- 实时监控活跃股池（自选 + 涨幅 / 成交额榜单，约 200 只，股池自动滚动更新）
- 异动类型：快速拉升 / 快速下跌、封涨停板 / 涨停打开、封跌停板 / 跌停打开、大单买入 / 大单卖出、量比放大
- 事件流实时推送，支持类型筛选、暂停 / 清空，点击联动 K 线 / 盘口；非交易时段自动待机

**预警管理（价格 / 涨跌幅触发 + 灵动岛推送）**
- 每只股票可设置：价格上穿 / 跌破、涨幅 / 跌幅阈值，多条件可并存，触发冷却可配
- 后端引擎盘中每 5 秒批量检测、冷却去重；触发即发**系统通知**，并**推送灵动岛**（自动展开、预警置顶、红 / 橙警示）
- 预警卡片集中管理：新增 / 编辑 / 删除 / 一键启停，显示最近触发时间

**F10 个股资料（公司概况 / 财务分析 / 筹码分布）**
- 公司概况：名称 / 上市信息 / 注册资本 / 董秘 / 联系方式 / 注册与办公地址，以及主营业务、公司简介
- 财务分析：最近 4 个报告期核心指标（每股收益、每股净资产、ROE、毛利率 / 净利率、营收 / 净利增速、资产负债率、流动 / 速动比率、总资产），可一键展开全部指标
- 筹码分布：基于日 K 换手衰减自算获利 / 套牢盘，ECharts 横向分布、标注现价与平均成本，显示获利比例、平均成本、90% 成本区间与集中度

**模拟交易（Paper Trading，零风险练盘）**
- 初始 100 万虚拟资金，遵循 A 股规则：100 股整数倍、**T+1**（当日买入次日可卖）、佣金万 2.5（最低 5 元）、卖出印花税千 0.5、过户费十万分之一
- 买入 / 卖出按实时价即时成交，数量支持 1/4、1/3、1/2、全仓快捷，实时预估成交金额与费用
- 持仓表显示成本 / 现价 / 市值 / 浮动盈亏与盈亏比，委托成交记录可查，支持一键重置账户
- 账户总览：总资产、可用资金、持仓市值、浮动与累计盈亏、累计收益率

**盯盘日记（Trading Journal）**
- 日历 / 列表双视图：日历标注每日篇数，列表支持按标题、内容、标签搜索，支持一日多篇
- 编辑器：标题、5 档心情、标签 chip 管理，可关联当前选中股票
- 一键插入复盘模板（大盘 / 操作 / 盈亏 / 心得 / 明日计划）
- 编辑后自动保存，支持删除

**财经日历（Economic Calendar）**
- 内置 2026 官方休市安排（元旦 / 春节 / 清明 / 劳动 / 端午 / 中秋 / 国庆），月历区分交易日、周末与节假日休市
- 本地财经事件管理：宏观 / 政策 / 新股 / 解禁 / 财报 / 其他六类，支持时间、备注、关联股票、完成态
- 事件可设到点提醒，届时系统通知推送；月历标注每日事件，便于提前布局重要节点

**新股 / 解禁日历（IPO & Lock-up）**
- 新股发行：对接巨潮资讯（AES mcode 签名），展示近一年全市场新股申购 / 上市安排
- 状态自动标注（待申购 / 待上市 / 已上市），发行价、市盈率、中签率、网上申购上限一目了然，支持按状态筛选；点行联动 K 线 / 盘口
- 限售解禁：选中股票即拉取其历次解禁队列（新浪），解禁日期、数量、流通市值、批次与公告日，未来解禁倒计时高亮、可一键只看未来
- **全市场解禁一览**：按 1 / 3 / 6 / 12 月区间汇总全市场解禁，滚动到底自动翻页、可加载全部；展示限售类型、实际解禁数量、解禁市值与占流通比例，点行联动

**灵动岛悬浮窗（金色奢华）**
- 右上角无边框置顶圆角胶囊，自动轮播自选股行情，脉冲提醒
- 点击展开「预警 + 智能异动提醒」列表，再次点击标题栏收起；点股联动主窗口
- **主窗口自选股增删 / 移动 / 分组改动实时同步**（事件即时刷新 + 3 秒轮询兜底），加载失败可点击重试、空自选明确提示，断网后自动恢复

**其他**
- 全新金色 TG 品牌图标，覆盖 Windows / macOS 任务栏、快捷方式与安装包
- 老板键 `Alt + ` ` 一键隐藏 / 恢复全部窗口
- 系统托盘常驻；SQLite 本地持久化（自选分组、行情、预警）
- 多数据源容灾（腾讯 / 新浪 / 东财），单源超时 / 异常自动切换 + 熔断
- 内置自动更新：更新对话框显示版本对比 / 更新说明 / 下载进度（百分比、MB、速度）；**检查与下载均多镜像容灾**（ghproxy / gh-proxy / 官方直连，用哪个镜像拉到清单就用同一镜像下载安装包），秒级检查、下载包经 minisign 签名校验，失败可重试或一键手动下载

## 下载安装

到 [**Releases**](https://github.com/mhxy881126/tickgold/releases/latest) 下载对应平台安装包：

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `TickGold_<版本>_x64-setup.exe`（图形化向导，支持自定义安装路径） |
| macOS Apple Silicon (M 系列) | `TickGold_<版本>_aarch64.dmg` |
| macOS Intel | `TickGold_<版本>_x64.dmg` |

> **Windows SmartScreen**：安装包暂未做代码签名，首次双击可能提示风险，选择「更多信息 → 仍要运行」即可。
> **覆盖安装 / 在线升级**：安装器会在安装前**自动结束正在运行的 TickGold（含主进程与 WebView2 子进程、托盘后台）**，多次重试并等待文件句柄释放，可直接覆盖、无需手动卸载（v0.19.1 起修复了个别情况下覆盖安装后主程序丢失、快捷方式失效的问题）。若你曾以「管理员身份」运行 TickGold，请先从托盘右键完全退出，再运行安装器。
> **macOS Gatekeeper**：未公证，首次打开请右键 app →「打开」一次。

## 从源码开发

环境要求：Node.js 22+、pnpm 10、Rust（stable）、VS Build Tools（Windows，含 C++ 桌面开发）。

```bash
pnpm install
pnpm tauri dev        # 启动开发模式（Vite 热更新 + Rust 后端）
```

仅验证前端：

```bash
pnpm build            # vue-tsc 类型检查 + vite 构建
```

验证 Rust release（`cargo check` 会被 Tauri build script 拦截，请用）：

```bash
pnpm tauri build --no-bundle
```

## 发版与持续集成（全自动）

仓库内置 `.github/workflows/release.yml`，**推送版本标签即自动发版**：

```bash
# 1. 同步版本号：src-tauri/tauri.conf.json 与 package.json
# 2. 提交并打标签
git add -A && git commit -m "release: vX.Y.Z"
git tag vX.Y.Z
git push origin main --tags
```

CI 会全自动完成：

1. 在 `windows-latest`（NSIS）与 `macos-latest`（aarch64 原生 + x86_64 交叉编译）并行打包、minisign 签名；
2. `publish` 汇总 job 生成三份 Tauri updater 清单：`latest.json`（官方直连）、`latest.ghproxy.json`、`latest.gh-proxy.json`（镜像下载 URL，扁平 `platforms.<目标>.{url,signature}`）；
3. 全部产物汇总到同一个 Release，资产就位后**自动解除草稿并发布**，客户端即可在线升级，全程无需手动操作。

> 发版前需在仓库 Settings → Secrets and variables → Actions 配置：
> `TAURI_SIGNING_PRIVATE_KEY`、`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`。
